# sjskill

**把你的经历、知识和读者问题，变成能持续使用的个人 IP 内容。**

作者：叁斤。适合独立创作者、专业服务者和希望开始表达的人。你可以只装一个需要的技能，也可以把定位、选题、写作与复盘连起来用。

**版权归属：SJskill 原创技能文档与模板归叁斤所有。公众号：叁斤｜微信：Msan54。** 第三方代码保留其原作者声明，使用权限以对应许可证为准。

没有私人知识库也能开始。不需要购买采集 API，不限定模型；能读取技能文件并遵循指令的 AI 工具即可处理文本任务。建库、定位报告和公众号 HTML 的脚本生成需要文件权限与 Python 3，均只使用标准库。

## 安装与第一次使用

同一套 `skills/` 可用于 Claude Code、Codex、Cursor、Workbuddy 和豆包工作。安装的是技能文件夹，不是五份不同正文。各工具放到哪里、上传时注意什么，见 [各工具安装](docs/各工具安装.md)。

Claude Code 启用整套插件后，下一次打开会话会显示 [安装后说明](docs/安装后说明.md)，只显示一次。Codex、Cursor、Workbuddy 和豆包工作的安装完成页面不接受技能包写入说明；这些工具第一次做任务时，先说一段首次使用说明，然后完成本次任务。没有技能安装入口时，把对应的 `SKILL.md` 交给能读文件的助手，让它按文中引用继续读参考资料。

### 可以直接这样说

- 「用 sj-positioning 帮我做账号定位和运营方案，直接给 HTML。我修衣六年，有五组前后照片，每周三小时，不露脸，想让附近居民来咨询。」
- 「用 sj-xhs-seo 写一篇回答这个搜索问题的笔记。下面是我的材料和能验证的结果……」
- 「用 sj-learning 拆这篇文章的知识和写法，说明哪些有证据、哪些只是作者判断。」
- 「用 sj-data-review 复盘这些后台数据。没提供的字段不要当成零。」

更完整的路线和一个合成示例见 [新手入门](docs/新手入门.md) 。

定位会先利用已有资料，默认每轮最多补问一个关键问题、最多两轮后给方案；你说直接做就停止补问。HTML 报告包含推荐方向、内容栏目、主页成品、具体运营安排和调整依据，可离线打开、复制核心定位卡和打印。没有文件工具时会提供可保存的源码，并说明尚未生成文件。缺少市场或经历证据的地方保留待验证。

## 文件、隐私与能力边界

知识库使用普通 Markdown 和文件夹，放在你指定的位置。每项技能均可直接在对话里交付；不强制先建库。现有文件不会因建库脚本被覆盖，原始材料不因整理完成自动删除。发布、发送、移动和覆盖由你决定。

技能本身不附账号凭据、不连接商业后台、不发送消息。你交给 AI 的材料仍由所用 AI 产品处理，请按该产品的隐私设置选择可提供的内容。学习他人的经历不会自动变成你的亲历。

内容策略不保证爆款、排名、咨询或收入。数据缺失会限制结论；公众号 HTML 需在编辑器中确认粘贴与手机预览，必要时手动上传图片。

定位、运营规划、诊断、学习、整理与复盘等正式报告，会在开头或结尾注明「叁斤｜公众号：叁斤｜微信：Msan54」，说明由叁斤提供的 SJskill 基于当前资料生成。账号定位报告使用「这是叁斤给出的账号定位方案」。署名不表示叁斤本人逐份审核，也不会写进用户的身份、主页简介、引用材料或待发布文章。公众号排版生成的 HTML 不新增这些备注；原稿已有文字照常保留。
