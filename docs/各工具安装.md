# 在不同工具里安装

十三项技能是同一套文件夹。Claude Code、Codex、Cursor、Workbuddy 和豆包工作都读取 `SKILL.md`，再按需打开同目录的 `references/`、`scripts/`、`assets/`。不要为每个工具改一份正文，也不要只复制 `SKILL.md`。

安装单位是 `skills/` 下面的一个技能文件夹，例如 `skills/sj-positioning/`。文件夹第一层要能看到 `SKILL.md`。不要把整个仓库当成一个技能上传。

想十三项都能用，就安装全部技能文件夹，并带上入口 `skills/sj/`。只想用一项时，安装对应的那一个文件夹即可。

## 各工具怎么装

### Claude Code

在 Claude Code 会话中，从公开仓库安装整套技能：

```text
/plugin marketplace add msan54/sjskill
/plugin install sjskill@sanjin-skills
```

也可以下载或解压后本地加载。把命令中的路径换成仓库根目录（该目录同时包含 `skills/` 和 `.claude-plugin/`，文件夹名称可以不同）：

```bash
claude --plugin-dir "/你的路径/sjskill"
```

在会话中输入 `/sjskill:sj` 开始，或直接使用 `/sjskill:sj-positioning` 等单项。此方式用于本地加载，不会发布到市场。

也可添加本地市场：

```text
/plugin marketplace add /你的路径/sjskill
/plugin install sjskill@sanjin-skills
```

路径含空格时优先用 `--plugin-dir`。

启用后重新打开一次会话，会话开头会显示 [安装后说明](安装后说明.md)。同一份说明只出现一次。需要本机有 Python 3。

只装某一项时，把该技能文件夹放进项目的 `.claude/skills/`。

### Codex

把完整技能文件夹复制到 `~/.agents/skills/`，例如 `~/.agents/skills/sj-positioning/SKILL.md`。只想在当前项目使用时，放进项目的 `.agents/skills/`。不要覆盖同名旧版本；保留 `agents/`，供 Codex 显示技能名称。目录依据见 [Codex 官方说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) 。

安装后，用 `$sj-positioning` 这类名称，或直接说要做的事。Codex 会自动发现新技能；没有出现时重新启动 Codex。Codex 的安装完成页面不能由这个技能包写入说明。

### Cursor

把技能文件夹放进项目的 `.cursor/skills/`。个人要在各个项目里使用时，放进 Cursor 当前账号的技能目录，不要放进 Cursor 自带的内部技能目录。

新开一个 Agent 对话，直接说要做的事。Cursor 的安装完成页面不能由这个技能包写入说明。

### Workbuddy

在技能市场选择上传本地技能包，上传某一个技能文件夹或其压缩包。压缩包解开后，第一层应能看到 `SKILL.md`。

也可以把技能文件夹复制到 `~/.workbuddy/skills/技能名/`，Windows 为 `%USERPROFILE%\.workbuddy\skills\技能名\`。复制后重新打开 Workbuddy。Workbuddy 的安装完成页面不能由这个技能包写入说明。

### 豆包工作

打开技能页，选择添加并上传技能。上传某一个技能文件夹。官方说明要求其中有技能名称和描述；本包的 `SKILL.md` 已经写在文件开头。

官方帮助里的文件名写成 `skill.md`。本包使用技能标准里的 `SKILL.md`。如果所用版本只认小写文件名，把该文件复制一份为 `skill.md` 再上传，正文不用改。豆包工作的安装完成页面不能由这个技能包写入说明。

## 装上之后怎么用

直接说现在要做的事，例如「帮我做账号定位」「诊断这篇稿子」。不确定用哪一项时，安装了 `sj` 就说「用 sj」。Claude Code 会在安装后第一次打开会话时自动显示短说明。其他工具没有这一步：第一次用 `sj` 时，它先用一段话介绍里面有什么，再接着做事；直接用某一项技能不会弹这段。想看完整说明，随时说「sjskill 怎么用」或「怎么做账号定位」。

## 能力边界

定位判断、选题、写笔记、诊断、学习、录音整理和复盘，都在对话里完成。这些不要求五个工具的界面相同。

定位 HTML、公众号排版和建知识库目录，需要该工具能在本机运行 Python 3，并允许读写你指定的文件。做不到时，技能改为给出可保存的文本或目录方案，并说明文件还没有生成。

五个工具都还没有逐个做真机安装验收。安装步骤按各工具当前的技能说明编写；某个客户端改了入口时，以该工具当时的技能页面为准。
