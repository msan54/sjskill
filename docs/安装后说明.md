SJskill 使用说明

SJskill 帮你把已有经历和材料做成能发出去的个人内容。定位、选题、写笔记、诊断稿子、公众号排版和复盘都可以单独用，不用按顺序走完。

打开后直接说你现在要做的事：

- 帮我做账号定位
- 给我几个能写的选题
- 写一篇小红书推荐流笔记
- 写一篇回答搜索问题的笔记
- 诊断这篇稿子哪里让人读不下去
- 把这篇公众号稿排成可以粘贴的 HTML
- 整理这段录音转写
- 学一下这篇文章
- 复盘这组内容数据
- 复盘今天做了什么
- 帮我建一个内容资料夹

想指定某一项时，可以说技能名：sj-positioning、sj-topics、sj-xhs-viral、sj-xhs-seo、sj-diagnosis、sj-wechat-format、sj-recording、sj-learning、sj-data-review、sj-work-review、sj-knowledge-base。不确定就说「用 sj」。

Claude Code 安装并启用后，下一次打开会话时会显示这份说明，只显示一次。其他工具在第一次做任务时，先用一段首次使用说明介绍里面有什么，并告诉用户可以说「sjskill 怎么用」或「怎么做账号定位」，然后立刻做这件事。
