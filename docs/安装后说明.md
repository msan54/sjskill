SJskill 使用说明

SJskill 帮你把已有经历和材料做成能发出去的个人内容。定位、建知识库、选题、拆对标、写笔记、诊断稿子、公众号排版和复盘都可以单独用，不用按顺序走完。

打开后直接说你现在要做的事：

- 帮我做账号定位
- 采访我，帮我建一个懂我的知识库
- 给我几个能写的选题
- 拆一下这篇对标笔记为什么能爆
- 写一篇小红书推荐流笔记
- 写一篇回答搜索问题的笔记
- 整理这段录音转写
- 学一下这篇文章
- 诊断这篇稿子哪里让人读不下去
- 复盘这组内容数据
- 复盘今天做了什么
- 把这篇公众号稿排成可以粘贴的 HTML

想指定某一项时，可以说技能名：sj-positioning、sj-knowledge-base、sj-topics、sj-benchmark、sj-xhs-viral、sj-xhs-seo、sj-recording、sj-learning、sj-diagnosis、sj-data-review、sj-work-review、sj-wechat-format。不确定就说「用 sj」。

Claude Code 安装并启用后，下一次打开会话时会显示这份说明，只显示一次。其他工具第一次用 `sj` 时，会先用一段话介绍里面有什么；想再看这份说明，随时说「sjskill 怎么用」。
