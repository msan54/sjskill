# 从一份真实材料开始

## 从零开始做账号

先把手里已有的背景和材料交给 `sj-positioning`，不需要先填问卷。它会利用现有信息，只有会改变方案的缺口才简短补问；你也可以说「直接给方案」。默认交付可打开的 HTML：账号定位、栏目与主页、首轮具体安排，以及反馈出现后如何调整。把其中的核心定位卡保存好，后续任务就不必重复背景。

想积累材料时用 `sj-knowledge-base` 建库；只想写一篇也可以跳过。再用 `sj-topics` 展开问题，选中你真想写且有材料支撑的题目。不要把「候选选题已生成」当作「每篇都能开写」。

写推荐流笔记用 `sj-xhs-viral`，回答搜索问题用 `sj-xhs-seo`。文章写完可以用 `sj-diagnosis` 看读者会在哪儿失去兴趣；它提供修改判断，不决定你有没有发布资格。公众号成稿用 `sj-wechat-format` 排版。

发布由你操作。获得数据后，把观察时间、内容目标和可用指标一起交给 `sj-data-review`。新发现可以回到下一轮选题；只有证据支持时才调整定位。

## 已经有录音或文章

录音先取得可读取的转写。`sj-recording` 不假装已听过音频，整理时会保留说话者与时间位置。会议决定、别人给你的建议、你想到但还没决定的事会分开。

文章用 `sj-learning`：想理解内容选知识学习，想学怎么写选写法学习，两者都要选双轨。没有链接读取能力时粘贴正文即可；只给一部分文章，就只分析这一部分。

需要保存时，一张卡回答一个可复用的问题，保留来源和适用条件。没有知识库时，直接拿对话里的报告使用。

## 一个完整的合成示例

以下人物与情境仅用于教学，不是作者或学员案例。

小林擅长修补旧衣，每周四小时，不愿露脸，有五份修补前后照片。她想让本地居民知道哪些破损值得修，不想承诺所有衣服都能恢复原状。

1. **定位**：围绕「舍不得扔但不知道值不值得修的衣物」讲选择方法；已有照片能提供依据。当地需求未调查，标为待验证。
2. **选题**：「牛仔裤膝盖破了，什么情况补完还耐穿？」是一道具体选择题；是否有接近破损位置的照片决定素材是否齐全。
3. **写作**：展示一份获准公开的修补过程，说明条件和不建议修的情况。没有实际耐穿测试，就不写「穿了三年还没坏」。
4. **诊断**：检查读者是否看完能判断自己的情况，而不只是看见一张漂亮成品图。
5. **发布与复盘**：登记发布时间和当时可读到的指标。出现「这种裂口能修吗」的追问，是具体需求信号；浏览高但无人问，并不能直接证明没有市场。

每一步都可单独完成。已有定位与材料的人可以直接开始写，不必重走访谈。

想查看 HTML 生成器的数据格式，可用定位技能内的 [合成示例](../skills/sj-positioning/assets/example-report.json) 与 [生成说明](../skills/sj-positioning/references/HTML报告与数据.md)。示例中的人物、材料与时间预算仅用于演示，不能当成你的经历或已验证运营成绩。

## 常见卡点

- **没有故事**：搜索教程可以靠真实步骤和演示成立；推荐流内容也可以围绕有证据的观察和判断，不编亲历。
- **只有截图**：先核对数字与字段，模糊处请补充；不把看不清的数字猜成零。
- **没有数据**：仍可诊断稿件和设计下一轮观察，不能声称已证明某种写法有效。
- **技能没安装全**：每项主技能包含所需参考；总入口发现缺技能会说明，不能假装调用成功。
- **图片粘贴不成功**：HTML 内已嵌入的图片仍可能被目标编辑器过滤。保留排版结果，按顺序上传本地图片，再做手机预览。
- **想更新已有文件**：先让 AI 对比新旧内容，确定修改目标；不要批量覆盖整个素材目录。
