# SJskill 维护约定

仓库根目录包含 `skills/`、`.claude-plugin/`、`docs/` 和 `tests/`，分别存放技能、插件清单、文档与可重复执行的检查。当前状态见 [项目进度](../ROADMAP.md) 。

- 每项技能可独立使用，参考文件随技能分发，不依赖作者的私人知识库或指定机器路径。
- Python 运行脚本只使用标准库；开发检查所需依赖另列在 `requirements-dev.txt`。
- 示例只能使用合成或已授权公开的材料。私人原料、对话、凭据、接管日志、旧安装包和测试缓存不进入仓库。
- 修改脚本后运行对应回归；目录或引用调整后运行发行结构检查。命令见 [开发与测试](开发与测试.md) 。
- 保留第三方署名及完整许可证，不擅自改变技能文档或脚本的授权范围。
- 文件产出不等于真实平台效果；未验证的安装环境、打印分页、后台粘贴或运营效果须明确说明。
- 未经明确授权，不提交 Git、推送远端或公开发布。
