# 拆解五步

## 第一步：还原它写给谁

不要先看它写了什么，先看**它假设读者是谁、卡在哪**。

- 这篇假设的读者是什么处境？在做什么、缺什么、怕什么？
- 它满足的是哪一种：**让人爽**（点赞）、**让人信**（关注）、**让人抄**（收藏）？看数据也能对上：赞多藏少偏「爽」，藏比赞高偏「抄」，评论里有人问「怎么联系你」「你还写过什么」偏「信」。
- **这一步答不清楚，后面全是瞎猜。**

## 第二步：拆四个零件

任何一篇能迁移的笔记，拆开都是这四样：

| 零件 | 问什么 |
|---|---|
| **人群** | 写给谁看的 |
| **场景** | 在什么具体情境下发生 |
| **冲突** | 读者心里那个「想要 A，却卡在 B」是什么 |
| **落点** | 看完读者带走了什么：一个方法、一个判断、一种情绪 |

**迁移的规矩：换人群和场景，冲突和落点原样保留。**冲突和落点才是它爆的原因，换掉就白搬了。

例：「青岛婚纱照价格怎么谈❓分享砍价＆避坑经验」——人群从准新娘换成你的客户，场景从拍婚纱照换成你的服务；「怕被宰」这个冲突、「给出具体避坑经验」这个落点，一个字不动。

图文笔记顺手看图：封面传递了什么、每张图在证明什么，图上的文字也算正文。视频看开头 3 秒用什么留人（一个问题、一个结果、一个反常画面），只有文字稿就不评价画面。

## 四层可见证据（拆的时候分开看）

判断爆的原因之前，先把风格、故事、叙事、情绪四层分开看。不能用「风格好」「故事感强」「情绪到位」一句话带过：

| 层 | 只看什么 | 不能猜什么 |
|---|---|---|
| 风格 | 人物、构图、道具、光色、声音、字幕和节奏里重复出现的规则 | 作者的人格、审美意图，或者长期风格已经成立 |
| 故事 | 谁想要什么、做了什么、遇到什么阻碍、结果怎样 | 正文和逐字稿里没写的经历、关系和心理活动 |
| 叙事 | 信息的先后、哪里展开哪里压缩、哪里重复哪里变化、哪里留白 | 作者为什么采用这个顺序 |
| 情绪 | 台词、关系变化、声音、动作和评论反应里能指出来的触发点 | 观众都产生了同一种感受，或者作者在「操控」某种情绪 |

每条关键结论都按四格记：

```text
结论：
证据位置：第几段／第几张图／第几秒
看得见或听得见的证据：
把握有多大，还有没有别的解释：
```

**形式种子候选**：至少两个视听要素在重复同一种感觉（比如固定的俯拍角度＋同一种暖光＋每段都用同一个音效收尾），可以提炼成一个「形式种子候选」：写清核心感觉，以及它怎样约束人物、空间、道具、光色、声音或节奏。只有一个滤镜、一个道具或一条作品时，不宣布风格已经成立，只写「候选，需要更多作品验证」。

**视频按段写「段落功能」**：拉片时每一段只写成片里实际发生的作用，比如「先展示结果，下一句才解释做法，形成了信息缺口」；不写看不出来的作者动机。只有逐字稿、没有画面时，画面、光色、动作都标「无证据」，开头 3 秒的文字抓手照样分析。

## 第三步：判断爆的原因

对着三个可能逐个排除：

- **角度**：它换了一个别人没用过的切入口吗？（可迁移，价值最高）
- **节奏**：开头几秒怎么留人，每一段为什么让人想读下一段？（可学）
- **平台**：是不是刚好赶上热点，或者账号本身有流量基础、有投流？（学不来，别硬套）

叙事层的证据对应「节奏」，故事层和情绪层的证据帮你判断「角度」有没有打中人；风格层只有形成了形式种子候选，才算能学的东西。

判断错了，仿写就是白费。看到一篇爆文先问：**换我发，还能爆吗？**

## 第四步：用用户自己的标准打分

拿 `说明书/我的内容标准.md` 逐条过这篇对标；用户没有这份文件，就先问他「你判断一条内容好不好看哪几点」。

**先说它哪条不合格。**你会发现爆款也有一堆不合格的地方：教程断在关键一步、标题许的东西正文没给、评论区一堆人在问同一个问题没人回——那些地方就是用户的机会。

## 第五步：迁移成用户的选题

先定档，再出迁移结果，做法见 [迁移与仿写](迁移与仿写.md)。

## 评论区怎么看

- 先留原话：高赞评论、反复出现的追问、反对意见，原样摘出来，去掉昵称。
- 滤掉水军：「好棒」「已关注」「互关」这类，不算需求。
- 样本够了再推：评论多、说法集中，才往下推这群人是谁、卡在哪；只有几条，就只当线索，不下「读者都这么想」的结论。
- 高赞的反对意见＝下一篇选题；反复出现的追问＝这篇没给到的东西，仿写时要补上。

## 批量拆解

逐篇走第一到第三步，每篇一行：`标题｜写给谁｜四零件｜爆的原因｜能不能迁移`。最后横向对比：几篇爆款共同的冲突是什么、共同的落点是什么、哪个原因出现得最多。批量只做拆解，不仿写；哪篇值得深挖，提醒用户单独走五步。

## 账号拆解

拆一个账号近期的 5—10 篇：

1. **内容结构**：题材怎么分布，图文和视频各占多少。
2. **爆款集中在哪**：哪几篇明显高于这个账号的平均数据，高出几倍；它们共同的人群、冲突、落点是什么。
3. **逐条讲爆款为什么爆**：按第三步的三个原因判断。
4. **和用户账号的差别**：哪些能迁移，哪些是它的身份、资源带来的，学不来。

结论写成四栏：这个号凭什么起来／能借的结构和选题／用户能迁移什么／不该学什么。
