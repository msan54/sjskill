# 复盘方法论：漏斗分诊法

复盘回答的唯一问题：**不是「数据怎么样」，是「下周改哪里」。**

> 基准值说明：下面的行业基准是起点，跑 3—4 轮之后，用你账号自己的实际数据校准；自己的历史数据永远比行业值准。

## 一、三平台漏斗映射表（核心工具）

同一套漏斗，三个平台只是指标名不同。**从上往下找第一个掉得狠的层，只修那一环，不全改。**

| 漏斗 | 小红书（图文／口播） | 公众号（长文） | 掉了 → 改什么 |
|---|---|---|---|
| ①被看到 | 曝光量；看流量来源（发现页、搜索各占多少） | 送达人数＋推荐曝光（看一看、推荐的占比） | 先核发布状态和取数口径，再看选题有没有踩中需求 → 换选题方向，去搜索框挖真实需求词 |
| ②被打开 | 点击率＝观看÷曝光：**<5% 必改，5%—10% 正常，≥11% 优质** | 打开率＝阅读÷送达：**1% 及格，2%—3% 不错，≥5% 很好**（行业均值只有 1.2%—2.3%） | 封面和标题 → 收集同选题的爆款标题拆解重写，封面加吸睛大字 |
| ③被看完 | 完播率：经验说法是 **<20% 会减推荐，>40% 进下一个流量池**；平均停留时长决定长尾 | 完读率：**2000 字 40% 以上、4000—6000 字 30%** 算好 | 开头和结构 → 重写开头前 3 句（悬念、点名困扰、展示结果），砍掉中段水分 |
| ④被认可 | 互动率＝（赞＋藏＋评＋转）÷观看：**1%—3% 及格，3%—5% 良好，≥5% 优秀，长期 <1% 说明内容有问题**；评论权重最高，转发次之 | 赞阅比 **≥2% 是底线（2.5% 好）**；转阅比 **≥5% 是底线（8% 好）——最值钱的指标** | 共鸣和信息密度 → 给可收藏的清单、步骤，删掉没有新信息的段落 |
| ⑤愿意继续关注 | 转粉率（≥1% 合格，对比自己的历史更准）、主页访问、评论里的持续追问 | 新增关注、常读用户占比（行业约 11%，头部账号可达 30%）、留言质量 | 人还没立住 → 回查有没有真实事件、个人判断，内容之间有没有连续性 |

**有产品或服务的账号，再加一层「来找你」**：

- **开口量**：看到内容后主动来问的人数——最核心的指标；不开口＝封面或内容有问题。
- **折损率**：开了口但没进微信、没下文——话术或内容和产品对不上。
- 每周只记三个数：开口量、加微数、线索质量（一句话）。

**短文案**：完读不是瓶颈，只看转发和评论。
**抖音**：至少记播放；同一条口播在小红书和抖音的表现差，可以当平台偏好的对照，不单独深复盘。

## 二、单篇分诊三原则

1. **先看量级再看率**：曝光只有几百的笔记，点击率波动很大，没有参考意义。先核发布和取数，再把问题归到①层（选题或账号权重），别急着改封面。
2. **只修第一个断层**：漏斗从上往下，第一个掉得狠的层就是主要矛盾；下面几层数据难看，可能只是上面的连带。
3. **别赖错组件**：内容不行，先倒推喂进去的素材是不是本身就空——输入是垃圾，就别怪输出。先补真实素材（亲身经历、数据、细节），再谈改写法。

### 单篇只能定位问题，多篇才能下结论

单篇可以告诉你「这条在哪里掉」，不能证明「这个方法以后都有效」。想知道一个改法有没有用，按控制变量的办法试：

1. 先写清这一轮的目标：要曝光、要看完、要互动、要精准关注，还是要有人来问。
2. 每一轮只重点改一个变量：选题、开头、结构、画面、节奏或互动点。
3. 其他条件尽量保持一致，连续发至少三条。
4. 先找这几条共同做对的动作，再看异常的那一条。
5. 视频出现明显掉点，回看掉点前 3—5 秒：那里是不是很久没有新信息、没有进度提示、在重复结论，或者跳得让人看不懂。
6. 留下有效的变量，再开始下一轮；不因为一条偶然的爆款就大改账号。

### 观众模型和关注者模型分开看

- **观众模型**回答：什么题、什么开头、什么画面让陌生人愿意停下来。
- **关注者模型**回答：哪些持续的行为、判断和关系让人愿意留下来。

播放高、但涨粉和主页访问弱，可能只是观众模型命中了，不代表人设或长期关系已经成立。评论也分两类看：在讨论主题的，和在评价「你这个人」的——后者反复出现，才说明人设在形成。

### 先建立生产基线，再做破圈实验

「70 分内容」不是平台的分数，是你自己现在能稳定做出来的质量底线，用你自己的内容标准和历史数据来定义。先连续做出一批同领域、同目标的合格内容，让主页能接住新来的人，再去做蹭热点、聊公共话题、强人设、升级制作这类破圈实验。每一轮实验先定一个目标和成功的证据，只改一个主要变量，至少看三条可比的内容再判断方向。偶然的爆款不触发立即转型：精准内容、主页和后续维护一起，决定一次爆发能不能变成长期的资产。

**分诊示例（虚构）**：一个 AI 办公账号的笔记「会议纪要别再手打了」——曝光 3200，点击率 4.1%，互动率 6.3%，涨粉 18。曝光量级够看；第一个掉得狠的是②被打开（低于 5%）；④互动率很好，说明点进来的人觉得有用。结论：内容没问题，封面和标题没让人点进来。动作：同一篇保留正文，封面改成「手写满页的笔记本 vs 三栏纪要截图」的对比图，标题前置「会议纪要」，下周重发对比点击率。

## 三、错误分析法（每攒 10—20 篇跑一次）

把「凭感觉复盘」升级成「按频率改进」：

1. **逐例标注**：拉最近 10—20 篇表现差的，逐条标「卡在哪一环」（①选题／②标题封面／③开头结构／④内容共鸣／⑤持续关注或来找你）。
2. **频率统计**：数每一环出问题的次数——高频环是系统性问题，不是运气。
3. **优先级＝错误频率 × 有没有改进思路**：高频又有招的先改；高频没思路的先放，别硬磕。先分清问题出在素材、目标、人工判断、AI 写作还是分发条件，确认是 AI 写作的问题，再走下面的改进阶梯。
4. **改进阶梯**（由易到难逐级试）：改写作方法或提示词 → 把跑赢的 1—2 篇当范文对照着写 → 换工具或换模型 → 把「一步写完」拆成「先写、再挑毛病改」两步。

## 四、周期层信号（单篇之上看方向）

| 信号 | 怎么看 | 说明什么 |
|---|---|---|
| 内容信号 | 按选题类型、写法分组，哪类稳定跑赢 | 有明确判断、立场的内容普遍强于纯情绪抒发——以自己账号数据为准 |
| 搜索流量占比 | 小红书搜索流量占比的走势 | 占比升＝搜索卡位在起作用，这类流量能吃很久 |
| 点赞和涨粉剪刀差 | 点赞、播放高，但涨粉、主页访问弱 | 让人爽的和让人信的不是同一类内容：话题吸引人，但人还没立住 |
| 涨粉和获客剪刀差（有产品时） | 涨粉好但开口少 | 内容有吸引力，但看完的人不知道怎么找你，回⑤层和主页修 |

### 正文对比四维度（读原文时用）

每次周复盘读本期最好的 2—3 篇和最差的 1—2 篇**原文**，按四个维度对比：

1. **开头类型**：经验排序——有对手的站队式 ＞ 真实事件、咨询案例式 ＞ 回应提问式（「最近很多人问我」）＞ 宏观论述式。叁斤自己账号第一次跑时：站队式 1881 阅读，事件式 1322 和 1078，回应式卡在 500—900，论述式 561。
2. **事件和读者的连接**：作者的真事能让读者看见自己的处境 ＞ 只有作者、没有读者的私人日记 ＞ 工具或技术当主角的说明文（工具当主角的内容普遍走弱）。
3. **交付感**：有没有读者能直接抄走的东西（清单、公式、改前改后对比）——决定分享率；纯认知论证读完认同，但不转发。
4. **实体密度**：可搜索的具体实体和数字 ＞ 抽象概念；带争议实体的站队内容，搜索和推荐都能吃到。

排序会随样本更新，以自己账号的最新数据校准，不迷信初始排序。

## 五、周复盘固定输出结构（8 项，短、直接、有证据）

1. 一句话结论。
2. 本周各篇分诊表（每篇一行：标题｜关键数据｜断在哪层｜改什么）。
3. 卡点频率统计（本周＋历史累积）。
4. 赛道信号＋写法规律（哪类选题跑赢、跑输；正文对比四维度的结论）。
5. 关注信号（转粉、主页访问、评论追问、收藏、转发）；有产品的另写获客三个数和环比。
6. **下周 3 个动作**（多写什么、少写什么、改什么——必须具体到能执行）。
7. 回流清单：验证过的需求方向 → 记进选题库并调高优先级；跑赢的写法 → 存为自己的范文；缺的素材 → 记下来去补。
8. 复盘方法哪里不好用：用户提出的校准（比如自己账号的点击率基准），记进 `数据复盘/我的复盘规则.md`，越用越贴自己的账号。

## 六、有产品或服务时：从曝光到成交的排查顺序

只在用户明确要复盘带货、获客或店铺内容时用：

1. **经营投入**：发布量、连续性、关键动作有没有变。
2. **曝光趋势**：从哪一天开始掉的，还是一直就没起来。
3. **异常核对**：掉的那几天前后，有没有违规、内容大改、价格或货盘变化。
4. **曝光 → 点击**：入口有没有让目标客户愿意点开。
5. **点击 → 商品卡或主页行动**：人群对不对，买点有没有把兴趣接到下一步。
6. **行动 → 购买或线索**：价格、详情页、信任、履约是不是成立。

从上往下找第一个异常节点，只修这一层：曝光不足时，不先改成交页；曝光大但下一步弱，先查人群错位和买点。

**人群护栏**：点击率、播放量、互动率只能说明抓住了某一批人，不能证明是对的人。高点击但吸引来的不是目标客户＝流量成功、经营失败，不能继续复制。每次复盘顺手看一眼：最近的高流量内容主要吸引了谁？评论、私信、关注的人和目标客户是不是同一批？

## 七、数据从哪来（低摩擦原则）

- 小红书：创作中心后台截图（笔记列表页＋单篇详情页的流量来源）。
- 公众号：后台「内容分析」截图（送达、阅读、完读、在看、转发）。
- 抖音：作品数据页截图（至少播放；有产品时另看私信和线索）。
- **入口＝把截图丢给 AI，说「数据复盘」**：AI 读图提数、更新总表、跑分诊，不用手填。
