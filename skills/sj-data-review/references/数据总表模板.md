# 内容数据总表（模板）

第一次用「内容复盘」时，AI 会把这份模板复制到用户指定的目录，作为他的数据总表（有知识库就存 `数据复盘/数据总表.md`）。之后每次复盘，AI 自动往里追加或更新数据。

- 同一篇内容的数据会随时间涨：复盘时更新原来那一行，并改「数据截止」日期，不重复建行。
- 读不出、没提供的格子填「—」；真实的 0 填 0。
- 只建用户实际在做的平台的表，空着的平台不用建。
