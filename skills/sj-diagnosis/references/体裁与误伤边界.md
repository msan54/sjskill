# 体裁与误伤边界

| 体裁／任务 | 重点看什么 | 不要强加什么 |
|---|---|---|
| 精准教程、搜索答疑 | 是否回答问题，步骤怎样推进，术语是否让目标读者理解 | 大众扩圈、亲身故事、反常识观点 |
| 生活随笔、情感表达 | 感受是否可辨，叙述与情绪有没有接上 | 积极结尾、行动清单、高潮和产品答案 |
| 公众号长文 | 主要期待与展开是否一致，转折和收尾是否完成任务 | 固定段长、固定材料数量或压缩比例 |
| 小红书图文 | 标题期待、正文回应、适合阅读的表达 | 拍摄术语、固定 emoji 数量、每句单独成段 |
| 口播文字 | 代词能否靠听明白，转折和语气是否清楚 | 只凭文本判断实际时长、音量或镜头效果 |
| 短文案 | 最影响当前表达的一两处关系 | 凑齐六行评分、为了完整加背景 |
| 公告、说明 | 对象、时间、动作和边界是否清楚 | 新颖角度与情绪转化 |
| 产品内容 | 承诺与正文回应是否相符，读者是否拿到需要的判断 | 默认必须成交或加联系入口 |

## 几个常见误伤

**窄受众并不自动是缺点。** 教初次用某工具的人保存文件，用准确的按钮名有帮助。标题换成「人生如何开始」反而让正文无法回应。

**平静并不等于没有节奏。** 一篇记录散步感受的短文，可以通过观察变化继续阅读，不必加挫折和振作。

**列表不自动等于 AI 味。** 比较规格、列准备物品或给操作步骤，清楚列出比强行叙事更适合。只有所有段落机械重复同一种表达，且伤害本文时才建议改。

**常识也能完成任务。** 读者第一次搜索操作方法，清楚的普通答案就有用。不为了「认知落差」加入不可靠反转。

**第一人称不是诊断准入条件。** 资料解读、观点评论和教程都可以没有作者经历。诊断者也不能因没有材料证明作者亲历而替作者补故事。

**句子包含抽象词未必需要替换。** 看目标读者是否需要这项概念、上下文是否解释清楚。把专业词硬换成长串生活比喻，可能更难读。

## 看见事实疑点怎么办

若原文同一处日期前后矛盾，或称最新却只有过期资料，局部注明「此事实待确认」，不给假结论。没有足够资料，不推断作者造假。用户要全面核查时再单独处理，不能把所有普通诊断升级为外部审计。

## 只有部分材料怎么办

只有标题，就评价标题可见的期待和前提，不断言正文未兑现；只有文字，就不评价未见图片。对于影响核心判断的缺失，写待确认。其余看得见的表达继续诊断。

若用户只问某一句，回答那一句的读法和最小改法即可。不能为了流程完整要求补定位报告、账号数据或全部原始录音。
