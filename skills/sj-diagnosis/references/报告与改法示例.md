# 报告与改法示例

以下原文与改法均为虚构教学材料，不代表真实读者反馈。

## 报告格式

完整稿可以先给简表：

| 项目 | 判断 | 原文依据／调整方向 |
|---|---|---|
| 读者关切与回应 | 成立等 | 指向具体句子或段落 |
| 普世化与受众开口 | 成立等 | 开口合适、可扩一层、过大或无需扩圈 |
| 角度陌生化 | 成立等 | 改变了什么，或为何无需反差 |
| 情绪与读者站位 | 成立等 | 文字把读者放在哪里 |
| 节奏与阅读牵引 | 成立等 | 依靠什么推进，哪里断开 |
| 去 AI 化 | 成立等 | 具体生硬处或成立的表达 |

然后列最值得改的问题。每条包含原文位置与短引文、读者可能的理解、对本文目的的影响、最小改法。没有问题的维度不凑建议，同一问题不在多项反复出现。

## 示例一：标题和正文答了两件事

原文标题：「不知道怎么给朋友发出第一次活动邀请」

正文：「我很喜欢组织活动。办活动能锻炼一个人的能力，也能认识新朋友。我打算把活动做成长期项目，慢慢建立自己的品牌。」

合适诊断：

> 读者关切与回应：关键处不成立。标题承诺解决「怎么邀请」，正文说明的是作者为什么想办活动。带着邀请困难来的读者可能仍不知道第一句话怎么发。若保留标题，正文应补具体邀请内容与对方需要知道的信息；若只想表达自己的打算，就把标题改成办活动的动机。

不要只说「缺利他性」「内容不够爆」，也不要在没获改稿授权时编一整段作者已经成功邀人的故事。

## 示例二：范围扩大后解释丢了

原文：「我没整理好一次活动的物料清单。所以人生所有焦虑，其实都来自秩序缺失。」

合适诊断：

> 普世化与受众开口：关键处不成立。「人生所有焦虑」超出了物料清单这件事能解释的范围。读者可能把一个局部教训理解成普遍归因。先缩回「准备活动时，漏项会增加临场的不确定」这样的范围；是否进一步谈其他焦虑，需要新的解释和条件。

局部改法用了原文已有关系，没有补具体漏了什么物品。

## 示例三：教程不必反常识

原文：「打开备忘录，新建一条记录。写箱号，再写这一箱的主要物品。装下一箱时换一个编号。找东西时先搜清单，再找对应箱子。」

合适诊断：

> 读者能按步骤完成标记和查找，操作前后接得上。受众开口和角度陌生化不适用：这段承担明确的操作任务，无须另加人生感悟或反转。若全文没说明如何把箱号标到实物上，那是应补的具体步骤；仅看此段，不断言全文一定遗漏。

## 示例四：没有证据就不能替读者宣布反应

原文：「别人的活动都办起来了，就你还在找借口。我写这些，是想让你轻松一点。」

合适诊断：

> 情绪与读者站位：建议调整。「就你还在找借口」把尚未行动直接归为逃避，与「轻松一点」的目的相冲突。读者可能感到被责备。可以指出具体拖延行为，避免替读者判动机；如果作者实际想强烈挑战读者，应把这项意图说明白。

不能说「读者一定讨厌你」或「这句会掉粉」，因为没有实际反馈。

## 示例五：原稿成立，可按目标扩一层

**原稿**：

> 标题：画册校样确认，版次和页码一起发
>
> 画册改完第 4 版，群里回了一句「没问题」，可对方回复的是第 3 版。我把版次和这次要确认的页码写在同一条消息里，再发校样。对方确认前，先对一下说的是哪一版、哪几页。

**用户目标**：「想让更多做过多人审稿的人看懂，印刷同行也要能用。」

**合适诊断**：

> 读者关切与回应成立：原稿直接回应校样确认时容易看错版本的问题。受众开口对原有读者也成立。按这次扩大读者的目标，可以做一项可选提升：从「确认校样」扩到「多人确认同一份文件」，共同处境是双方说着同意，却可能看着不同版本。现有事件足以解释这一层，不需要扩成「所有沟通失败」。

**最小改法**：标题可换成「一句『没问题』，确认的是你刚改的那一版吗」。正文在原事件前补一句：「几个人一起改一份文件时，对方说没问题，你们眼前也未必是同一版。」随后保留第 3／4 版、校样、版次和页码；最后的核对动作沿用原稿。

这项改法让相邻读者先认出自己遇过的问题，再通过具体校样理解怎么核对。没有新增效果、客户身份或更多行业案例。专业细节说明错在何处，不能删成「有效沟通需要共识」；未提供读者反馈，仍不声称扩写后一定更受欢迎。

如果用户目标只是给印刷同事一份准确的校样确认说明，保留原题和原文即可。报告应写「原稿成立，扩写为可选」，不能把用户选择不扩写判成质量不合格，也不产生发布准入结论。

## 结论写法

合适：「邀请这件事很具体，值得保留；先补对方收到消息后需要知道的内容，其余语气可以沿用。」

不合适：「综合评分 82，可发布。」「没有真实案例，不能发。」「这明显是 AI 写的。」

用户要求改稿后，按诊断优先级改，并列出影响事实、结构或立场的变化。缺事实不能靠代写填满，不用再次重复请求已经给过的改稿授权。
