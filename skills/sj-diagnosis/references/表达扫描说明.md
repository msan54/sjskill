# 表达扫描说明

`scripts/check_prose.py` 是可选的只读辅助工具。普通六维诊断不必运行；用户点名机械扫描或长稿需要定位重复表达时使用。需要 Python 3.10 或更新版本，仅用标准库。

先解析本技能目录，再以绝对路径运行，例如将下方占位路径替换成实际安装位置：

```bash
python3 "/实际安装位置/sj-diagnosis/scripts/check_prose.py" "/用户指定路径/稿件.md" --genre xhs
```

也可从标准输入读取：

```bash
python3 "/实际安装位置/sj-diagnosis/scripts/check_prose.py" - --genre short
```

`--genre` 支持 `auto`、`wechat`、`xhs`、`voice`、`short`。自动模式只按元数据、文件名和文本长度粗分体裁，不适合用作正式判断；已知体裁就显式指定。

## 提供什么

脚本定位重复翻转、路标词、抽象业务词、长前置句、重定语、短段排队、段落开场重复和混用比喻等形状，输出原始文件行号与片段。它不改文件，不访问网络，不写报告文件。

程序内的数字是减少提示噪声的采样参数，只决定显示哪些线索，不是中文写作标准、平台规则或诊断阈值。某句未被扫描到，不说明表达一定自然；命中也不说明错误。

开头 YAML 元数据、代码、链接目标以及明确标作生产档案等的尾部备注会被遮蔽，保留行号。没有明确分隔的创作备注可能被当成正文；输入前尽量只取读者将看到的部分。扫描对中文稿件设计，正文没有汉字时会报告不适用，不能把它当作英文质量验收。

## 结果怎么用

回到原文，按体裁判断它有没有造成理解困难。只有能写清原句、读者可能卡住的地方和局部改法时，才纳入第六项「去 AI 化」；句式与阅读牵引真正相关时说明关联，不重复列问题。必要的术语、强调和有意排比应保留。

不检查经历真假、来源权限、材料数量、平台合规，也不输出总分、AI 概率或发布资格。成功退出仅表示扫描完成；输入不存在、无法按 UTF-8 读取或没有正文汉字时，退出码为 2。
