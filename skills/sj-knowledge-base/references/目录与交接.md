# 目录与交接

本文件三部分：采访产出的每个文件写什么、协作协议模板、SJskill 其他技能怎么读这套目录。目录结构本身见 [知识库说明模板](知识库说明模板.md)。

## 一、采访产出的文件写什么

每个文件只写用户说过的话。没答上来的写「待补」，不留空着不说明，也不编。

**`说明书/我是谁.md`**：一句话身份（他实际在干的活）；做了多久、之前做什么、为什么转过来；同行没有的东西；最好的一次结果（带数字和时间）；看不惯的做法和自己不一样的做法；一句话自我介绍。

**`说明书/我的客户.md`**：客户是谁（年龄、职业、城市、阶段）；找到他时卡在什么问题上、自己试过什么；最常问的三个问题；在哪里看内容；自己做主还是要商量；不想接的客户；最想多接的那一类。

**`说明书/我的风格.md`**：说话的调性；口头禅；绝对不说的话；行业合规红线；最讨厌的表达；发过的最像自己的一条、后悔的一条；希望别人留下的印象。

**`说明书/我的对标账号.md`**：2—3 个具体账号，每个写喜欢它哪一点、它的标题有什么手法。

**`说明书/我的内容标准.md`**：每条标准写成一个能回答是或否的问题，后面附他当时的原话。例：

```markdown
- [ ] 开头三句里，有没有一个具体的人在做一件具体的事？——「我最烦一上来就讲道理的」
- [ ] 读者看完，能不能带走一个马上能用的东西？——「收藏的都是能直接抄的」
- [ ] 有没有一句我自己不会说的话？——「看到『赋能』这种词我就划走」
```

**`产品库/产品说明书.md`**：有几种产品、主推哪个；形态、价格、怎么收费；交付流程一步步写；多久见结果；定价依据；入门款和高阶款各卖给谁；跟同行的具体差别；不做什么。

**`产品库/买点清单.md`**：客户自己说的选择理由，一条一行，后面写是哪个客户、什么时候说的。客户说的和他自己以为的不一样时，以客户说的为准。

**`产品库/常见异议.md`**：问过价没买的理由、其他顾虑，每条后面附他平时怎么回（原话）。

**`素材库/真实案例.md`**：一个案例一节——谁、什么时间、发生了什么、最后结果（有数字写数字）、能证明什么。成功和失败的都要。

**`素材库/客户原话.md`**：三列表格。

```markdown
| 原话 | 什么场景说的 | 能用来干什么 |
|---|---|---|
| 「我就是不知道第一句该怎么写」 | 第一次咨询时 | 写开头类选题的入口 |
```

## 二、协作协议模板

按用户的工具生成 `CLAUDE.md` 或 `AGENTS.md`，两个都生成时内容完全一致。文件已存在就先读，问用户合并还是另存，不覆盖。

```markdown
# 我和 AI 的协作协议

AI 每次开工先读这份。这里只放规矩。东西放哪，看 `知识库说明.md`；我是谁、我的客户、我的风格、我的内容标准，需要时去 `说明书/` 读，不要每次都把它们当成前提。

## 红线（违反即灾难，无例外）
- 禁止移动、重命名、删除任何已有文件——AI 删掉的文件不一定进回收站。
- 禁止自动提交或发布——发出去收不回来。
- 动手前先说清楚要读什么、写什么、改什么，等我确认。

## 质量底线
- 新建文件前先看路径是否已存在，不覆盖——覆盖了就找不回原来的版本。
- 多步骤的事先列计划再执行，不默默做完——做错了我来不及拦。
- 不确定放哪就问，不猜路径——放错地方等于没放。

## 任务铁律
- 先问清、再规划、后执行；任务模糊就追问，不脑补——脑补出来的都是最多人写过的那种话。
- 我没说过的话，不替我写进知识库——知识库里出现一句我没说过的话，整个知识库就不可信了。

## 知识库规矩
- 新东西进来，先跟已有的核对：重复的只留一份；是升级就更新原来那份；说法冲突就两种都留，写清各自在什么情况下成立；真是新的才新建。
- 别动不动新建文件夹，先看现有目录放不放得下——目录越多，越找不到东西。
- 同一件事只能有一个地方说了算：价格、规则、数字只写在一个文件里，别处引用——两处写法一不一样，AI 就会各听各的。
- 写内容时，需要案例才去素材库找，带着「我要一个能证明这件事的案例」去找，不先把素材库翻一遍——先翻一遍，写出来的就永远绕着那几个旧案例转。

---
本文件与同目录的另一个协议文件内容必须一致，改了一个记得同步另一个。（只生成一个文件时删掉这句）
> 目录结构与协作规则来自叁斤的 SJskill｜公众号：叁斤｜微信：Msan54
```

## 三、SJskill 其他技能怎么读这套目录

| 技能 | 读哪里 | 写到哪里 |
|---|---|---|
| sj-positioning（账号定位） | `说明书/`、`产品库/` | 核心定位卡存 `说明书/定位报告.md` |
| sj-topics（选题） | `说明书/`、`素材库/客户原话.md` | `选题库/` |
| sj-xhs-viral（推荐流笔记） | `说明书/`、需要时定向读 `素材库/` | `待发布/` |
| sj-xhs-seo（搜索笔记） | `产品库/`、`素材库/` | `待发布/`、`选题库/关键词库.md` |
| sj-diagnosis（诊断） | `说明书/我的内容标准.md` | 只在对话里给结论 |
| sj-recording（录音整理） | `输入/录音/待处理/` | 整理稿进 `输入/录音/已处理/`，真事和原话进 `素材库/`，做法进 `方法论/`，选题进 `选题库/` |
| sj-learning（文章学习） | `输入/内容学习/` | 学习笔记和学完的原文进 `输入/内容学习/已学习/`，学到的方法进 `方法论/` |
| sj-data-review（内容复盘） | `已发布/` | `数据复盘/` |
| sj-wechat-format（公众号排版） | `待发布/` | 稿子旁边的 `公众号HTML输出/` |

每个技能动手前都会先读 `知识库说明.md`，所以你改了存放习惯，只改那一份就行。
