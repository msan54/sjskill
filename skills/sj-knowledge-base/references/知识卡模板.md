# 知识卡模板

一张卡回答一个之后还会遇到的问题，独立阅读应能知道如何用、何时不能用。

```markdown
# 具体标题

## 要回答的问题
谁在什么情况下需要这个判断？

## 结论或操作
给出判断、理由或步骤。案例写事件与结果，需求卡写问题原话与处境。

## 适用与不适用
哪些前提必须满足？出现什么反例时不能照用？

## 证据与来源
材料名、作者／说话者、日期（已知时）、页码／段落／时间戳或相对文件链接。

## 内容性质
区分来源事实、作者解释、模型提出的应用假设。本人经历需有用户确认。
```

这是字段示范，不自动创建带占位词的空卡。无意义的空字段可省略，证据位置和内容性质不能省。

同一结论有新证据时先检查旧卡：相同就补来源，冲突则并列适用条件，不静默覆盖。长篇材料需要多个问题卡，但不要把每句话都拆成一张卡。
