# 五维写法与迁移：这篇是怎么写出来的

每一维都按同一个格式写：**原文在哪＋必要的例句 → 它在这篇里起了什么作用 → 下次怎么用 → 什么时候不适用**。不写「情绪共鸣强」「结构清晰」这种空评价，大段原文也不用复制，只留能说明问题的那一句。

## 一、选题角度

- 写给谁？这个人在什么处境下会停下来读？
- 踩中了什么情绪或需求？
- 为什么切这个口子，而不是常规那个？先写出大多数人会怎么写这个题，再对照它的切法，反差就出来了。
- 标题写给所有人、正文却只有某个行业的人看得懂的，照实写出它真正的读者是谁。

## 二、写作框架

逐段拆，保留原来的顺序。每段写它「在干什么」，不只写「讲了什么」：

| 位置 | 写了什么 | 这段在干什么 | 给下一段留了什么问题 |
|---|---|---|---|
| 第 1—2 段 | 一个具体的失败场景 | 让读者认出自己 | 为什么老是这样？ |
| 第 3—5 段 | 作者的解释和一个案例 | 撑起一个原因判断 | 那怎么改？ |

表里是示意，不是每篇都这个顺序。

看清：主张靠什么证明、在哪转折、案例什么时候出场、结尾回答了开头的什么。作者中途换了问题、证据不够、结尾没兑现开头的承诺，照实写，不把每一段都说成精心设计。

最后提炼成能套用的骨架，比如「一次具体的失败 → 大家一般怎么解释 → 一个反例 → 新的解释 → 一个小动作」，并写清适合什么题材。不能只交「开头—中间—结尾」。

## 三、开头钩子

拆前 3 句：

1. 第一处具体信息是什么？读者能不能看见一个人正在做一件事？
2. 抛出了什么还没回答的问题、反差、后果，或者许诺了读者能得到什么？
3. 哪一句让读者觉得「说的就是我」？
4. 后文兑现了这个承诺没有？

没有阅读数据，只写这句话起了什么作用，不说它「留住了多少人」。

## 四、语言手法

只挑会改变读者理解或感受的用法，标出具体例句和位置：

- **金句**：用的是对照、因果、递进，还是给老东西起了个新名字？去掉修辞还剩什么判断？
- **类比**：用读者熟悉的什么，解释了哪个难点？到哪一步就对不上了？
- **数据**：在交代规模、反差还是结果？有没有来源、对比的基数和单位？
- **原话**：留住了现场感、立场差异，还是真实的顾虑？转述不能写成原话。
- **节奏**：长短句、段落疏密、重复和停顿，在哪里让人读快了，在哪里让人停下来？

## 五、可复用模板

从观察里提炼做法，不是把原文挖空换名词。具体到「下次写 XX 类内容时怎么套」：

```markdown
写法名：
现在的状态：单篇观察／可复用写法／业务验证
解决什么写作问题：
适合什么题材、什么读者：
需要什么真实素材：
按什么顺序写：
每一步要回答什么问题：
什么时候不适用：
📌 来源：文章标题＋作者＋第几段
🎯 应用：在哪篇稿子里用过；没用过写「待补」
```

**示例（虚构）**：一篇公众号文章《周报写了三年，我才发现领导只看第一行》，开头是「周五下午五点，我交了周报。周一开会，领导只问了一句：『这周最重要的一件事是什么？』我愣住了——那件事写在第四段。」从这一段抽出的模板：

```markdown
写法名：开头先放一个被问住的瞬间
现在的状态：单篇观察
解决什么写作问题：教程类开头太平，读者不知道为什么要往下看
适合什么题材、什么读者：职场技巧、工具用法；写给天天在做这件事、但没意识到哪里有问题的人
需要什么真实素材：一次真被问住、被退回或出错的经历，有当时的原话
按什么顺序写：被问住的那一刻（原话）→ 答案其实写在哪 → 一句判断：问题不在写得少，在顺序 → 方法
每一步要回答什么问题：读者有没有过同样的时刻？答案藏在哪？顺序错在哪？
什么时候不适用：手上没有真被问住的经历——编出来的瞬间，读者一眼能看穿
📌 来源：《周报写了三年，我才发现领导只看第一行》第 1—3 段
🎯 应用：待补
```

## 六、两项检查

- **反例**：什么题材、什么读者不适合这套写法？
- **迁移测试**：换一个完全不同的主题，按同样的顺序试写一段。只换了几个名词就写出来的，不算通过；每一步还在干原来那件事（提的问题是真的、反例站得住、结论有新证据撑着、结尾兑现了开头），才算通过。试不通，写下在哪失效、缩小适用范围，不硬凑场景证明模板没问题。

状态怎么升：单篇里看到的是「单篇观察」；同一个手法在两篇不相干的文章里都出现，或者迁移测试通过，升成「可复用写法」；用户真的用它发了内容、有数据，才算「业务验证」。试写通过不等于发出去有效果。

## 七、「为什么能爆」

先排除学不来的：赶上了热点、账号本来流量就大、投了流。剩下的再看角度和节奏——角度能迁移，节奏能学。没有数据时，回答「这篇有哪些可能帮它传播的写法」，不把某一个钩子说成唯一原因。
