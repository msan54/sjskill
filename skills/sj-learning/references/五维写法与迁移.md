# 五维写法与迁移

## 一、选题角度

回答「谁在什么处境会停下来读」「他想解决什么，或正承受什么感受」「作者选了什么观察位置」。把普通切口与原文切口做简短对照，反常识不是必选项；平常角度也可能靠具体经历成立。

区分读者在乎的问题与作者想表达的观点。标题写给所有人，正文却依赖某种职业经验时，指出实际受众范围，不替文章扩成普世话题。

产出：读者处境、核心问题、切入角度、原文证据，以及角度成立所需的素材。

## 二、写作框架

按自然段或功能段拆，保留原顺序。每段写「承担什么作用」而不是只写「讲了什么」。

| 位置 | 可见内容 | 段落作用 | 给下一段留下的问题 |
|---|---|---|---|
| P001—P002 | 原文的具体场景 | 让读者认出自己的困境 | 为什么反复发生？ |
| P003—P005 | 作者解释及案例 | 支撑一个原因判断 | 那要怎么改变？ |

这是分析表的示意，不预设所有文章都应按这个顺序写。

找出主张如何得到证明、哪里转折、案例何时出现、结尾答复了开头什么。作者中途换了问题、缺少证据或结尾没兑现承诺时如实指出，不把每一段都解释成有意设计。

最后提炼成「功能骨架」，例如「具体失败 → 读者惯常解释 → 一个反证 → 新解释 → 小动作」，并写清它适用的题材。不能只交「开头—中间—结尾」。

## 三、开头钩子

从实际前几句分析，不强制每篇都有三句完整钩子。

1. 第一处具体信息是什么，读者能不能看见一个人正在做事？
2. 有什么尚未回答的问题、反差、后果或阅读承诺？
3. 哪句话让读者觉得与自己有关？这来自内容本身还是分析者猜测？
4. 后文是否兑现了这个承诺？

指出作用时保留可能性：「这句话提出一个尚未解释的反差，可能促使读者往下找原因」。没有停留／阅读数据，不断言这句话实际留住了多少人。

## 四、语言手法

只挑会影响读者理解或感受的具体用法；不必为每类都找例子。

- 金句：对照、因果、递进还是重新命名？删掉修辞后还剩什么判断？
- 类比：用熟悉对象解释了哪个难点？对应关系在哪里失效？
- 数据：交代规模、反差还是结果？有来源、基线和单位吗？
- 原话：是否保留现场感、立场差异或真实顾虑？不能把转述写成逐字引文。
- 节奏：长短句、段落密度、重复和停顿怎样改变阅读速度？具体标出位置。

每个重要手法使用同一小结构：必要短引文＋段号 → 实际作用 → 可借用步骤 → 不适用条件。不要大段复制原文；只有精确用词影响分析时才保留引文。

## 五、可复用模板

从观察中提炼操作，不是挖空原文换名词。

```markdown
写法名：
当前状态：单篇观察／可复用候选／有真实使用记录
解决的写作问题：
适用题材与读者：
需要的真实素材：
功能顺序：
每步需要回答的问题：
不适用场景：
来源：标题、作者、句段位置
应用：本次迁移测试／用户已使用稿件；没有则写待试
```

保留来源和应用两端：来源证明此观察从哪里来，应用记录它后来有没有帮助。未使用时允许应用栏为空或待试，不虚构发布记录。

## 迁移测试

1. 换成不同的读者问题和真实素材；材料不足就用明确标注的虚构教学场景，不借用用户身份。
2. 按功能顺序写一个短开头、论证段或结构提纲。无需自动写完整文章。
3. 检查每一步是否仍完成原来的作用：提问是否真实、反证是否有效、结论是否由新证据支持、收尾是否兑现承诺。
4. 失败时记录失效条件并缩小适用范围，不为了证明模板正确硬凑场景。

单篇观察跨两篇独立内容复现，或迁移测试通过后，可记为「可复用候选」。这只说明写法可以迁移，不保证阅读、互动或成交。只有用户提供真实发布稿和相应结果，才能记「有真实使用记录」；单次结果也不叫普遍规律。

## 「为什么能爆」的证据边界

没有数据时，改答「这篇有哪些可能支持传播的写法，以及哪些只是推测」。有互动量也只能说明观察到的表现；题材热度、账号受众、发布时间、投放和推荐来源可能同时影响结果。缺乏对照，不把某个钩子或句式称为唯一原因。
