# 定位判断：方法与判据

本文件是生成方案时的判断依据，格式为「规则＋判断标准」，供内部推演调用，不直接展示给用户。

## 0．定位总纲

- 定位＝出发时的指南针，不是终点。允许初始模糊，在「做」的过程中迭代清晰。方案里要传达这个预期，防止用户追求完美迟迟不动手。
- 定位＝选择＝舍弃。明确服务谁、提供什么，同时明确**不服务谁、不提供什么**。
- **定位从变现倒推**（五环闭环：变现 → 定位 → 产品 → 内容 → 流量）：
  - 想接广告 → 选商单多、报价高的赛道，内容里预留广告位。
  - 想卖货／带货 → 选销量好、自己有产品优势的赛道。
  - 想引流私域 → 内容围绕自己的产品或服务建立专业信任。
  - 暂时不想变现 → 倒推他想要的结果（作品集、同行圈子、个人表达），内容为这个结果服务。
- 方向选择铁律：做自己**擅长、喜欢、且离钱近**的方向，三者取交集。

## 1．五项公式：价值 × 用户 × 人设 × 类型 × 风格

**账号定位 ＝ 价值 × 用户 × 人设 × 类型 × 风格。** 五项要互相对得上：价值说得很清楚却找不到对应的人群，或者人设很有趣但内容类型撑不住，都不算定位完成。

| 项 | 回答什么 | 写到什么程度算过关 |
|---|---|---|
| 价值 | 帮用户在哪个场景解决什么问题 | 一两句话，用户看完知道关注你能得到什么 |
| 用户 | 你为谁做 | 能想象出一个真实的人 |
| 人设 | 用户凭什么信你、记住你 | 角色关系＋2—3 个性格标签＋一个记忆点 |
| 类型 | 用什么形式呈现 | 主形式＋为什么适合他的时间、技能和出镜条件 |
| 风格 | 看起来、听起来是什么样 | 视觉一句、语言一句，换个人也能照着做 |

## 2．用户定位

**先定方向：做 IP，不做网红。**

- 网红：提供娱乐陪伴，被「消费」，姿态偏服务，讲究天时地利人和。
- IP：提供专业价值＋信任背书，被「追随」，能影响用户决策；有复利效应，做得越久积累越多，变现越大。人人可做。

**画像标准：具体到「想象一个真实的人」。** 四个维度拼出画像：

1. 基本信息：年龄段、性别、城市级别、职业／身份。
2. 经济水平：收入范围、消费理念（性价比／品质／品牌）、消费习惯。
3. 生活状态：婚恋、生活节奏、居住环境。
4. 内心世界：近期烦恼、渴望、兴趣、常刷什么内容。

判断标准：画像具体到位后，应该能直接回答「她想看什么、用什么语气跟她说话、什么能打动她」。答不出＝画像还不够具体。

「25 岁女性」不是画像：每天通勤两小时、早上只肯花 5 分钟化妆的打工人，和准备考研、买东西只看性价比的学生，看同一条笔记的反应完全不同。**一个账号先锁一种人打透**，相邻的人群以后再扩。

**拆人四依据**：同一个标签下按四把刀拆，按优先级用——①身份或角色（职场白领、全职妈妈、自由职业者）；②动机（同样考研：真喜欢、被人刺激、赌一把上岸）；③场景（同样买粉底液：上班用、拍视频用、敏感肌用）；④人生阶段（同样 35 岁：刚结婚、孩子上小学、刚离婚）。拆到 3—5 种最实用，不穷举。两条检验：拆出来的每种人，能不能起个名字、想象出她的一天？任意两种人看同一条内容，反应会不会不同？相同就合并，没必要拆。

**用 5W1H 把人翻译成内容方向**：

- WHO：最有辨识度的身份描述——不是「25 岁女性」，是「刚转正、每天挤一小时地铁的互联网运营」。
- WHEN：她正在经历的人生阶段。
- WHY：她要靠这件事实现什么（说人生需求，不说产品功能）。
- WHERE：需求最强烈的那个场景。
- WHAT：这个场景下她要的具体东西。
- HOW：她会搜什么词、在什么话题下出没。

**拆出来的人不能都打，按四项各打 1—5 分挑先做谁**：

| 项 | 看什么 |
|---|---|
| 痛感强度 | 每天都遇到、反复去搜、主动来问 |
| 付费证据 | 已经在为这件事买课、买工具、进社群 |
| 现有产品接得住 | 不用重做产品，改一改表达就能服务他 |
| 内容供给 | 用户有没有素材能持续写给他：案例、经历、截图 |

16—20 分：第一优先，单独做一条内容线；12—15 分：第二优先，用一组系列内容试；8—11 分：偶尔覆盖；4—7 分：暂不投入。现有产品接不住的人群再大也不是优先级；只「感兴趣」、没有付费证据的降一级；痛感强但没素材的，先小范围试。没有产品、暂不变现的用户，「付费证据」和「现有产品接得住」两项换成「他会不会持续关注」「你能不能持续回答他的问题」。

## 3．价值定位

**一句话说清：帮用户在哪个具体场景下，解决哪个具体问题。**

两种价值策略（按用户 Q2、Q12 的回答选）：

- **目标明确型**：① 免费内容吸引 → 建立信任 → 变现（广告、电商、知识付费通用）；② 直接服务特定付费人群，提供精准高价值内容。
- **价值深耕型**：变现目标暂不清晰时，聚焦最擅长、最热爱的领域持续输出，先聚同频用户，再按用户需求探索变现。

两大定位误区（生成方案时自检，也用来点醒用户）：

- **极端工具人**：内容全是干巴巴的知识点，像行走的百科全书 → 后果：没粘性、不容易被关注 → 解法：用个人观点、经历、情绪串联知识，用「人」带「知识」。
- **过度抽象**：泛泛而谈「生活」「成长」「情感」 → 后果：用户不知道关注你能得到什么 → 解法：找具体、可感知、利他的切入点；分享生活也要提炼出对别人的启发或实用信息。

## 4．人设定位：七维挖掘

人设是连接你、用户和价值的桥梁。逐维检查用户的访谈回答，至少激活其中 3—4 维：

| 维度 | 挖什么 | 用法 |
|---|---|---|
| 1 故事性 | 转折点、冲突、高光、失败反思、反差感（学霸做搞笑、理工男讲护肤） | 反差是最强记忆点；同一个故事可以多角度反复讲 |
| 2 性格品行 | 逻辑强还是共情强？幽默还是沉稳？别人怎么评价 | 选能吸引目标用户的 2—3 个特质放大 |
| 3 与观众的关系 | 四选一：提醒者／导师、服务者、娱乐者、引领者 | 关系定了，说话方式、语气、用词全部要匹配 |
| 4 三观 | 赞同什么、反对什么、行业立场 | 一致的表达吸引三观一致的用户；可以凝练成简介里的态度标签 |
| 5 愿望渴望 | 想要什么生活、追求什么目标 | 让用户觉得真实、离自己近，吸引同路人 |
| 6 情绪基调 | 最自然流露的情绪：激情／冷静／温暖／犀利／治愈 | 早期保持一致，让用户形成稳定预期 |
| 7 思维习惯 | 逻辑思维还是形象思维 | 对应讲故事、讲知识、展示过程、记录日常四种形态，选最擅长的 |

人设靠持续的行为立住，不靠自我介绍宣布。用户说自己「靠谱」，方案里要写成每篇能看见的动作：怎么核对信息、怎么说清适用条件、出错了怎么改。

## 5．内容类型

按 Q8（擅长的表达）、Q3（时间与出镜）、Q13（技能底子）选主形式：

| 擅长 | 适合的主形式 | 典型内容 |
|---|---|---|
| 讲故事 | 口播视频、长图文、Vlog | 经历复盘、转折故事、观点 |
| 讲知识 | 干货图文、口播 | 攻略、清单、避坑、对比 |
| 展示过程 | 过程图文、手部视频 | 教程、改造、前后对比 |
| 记录日常 | Plog、Vlog | 生活方式、职业日常 |

- 新手、技能底子弱、时间少：**图文先行**。图文制作快、改起来容易，适合先验证选题；跑通了再拍成视频。
- 不露脸也能做：屏幕演示、手部过程、实物和场景、图文讲解。
- 主形式定一个，辅助形式最多一个，别一上来图文、口播、Vlog 全铺开。

## 6．风格：视觉与语言

**昵称**（给 2—3 个候选，标出首选和理由）：

- 好记易传播：简洁上口，忌生僻字、特殊符号、过于大众化。
- 体现定位或人设：「XX 测评官」「设计师 XX」「XX 的日常」。注意天花板：叫「XX 家电测评」就基本锁死家电赛道，内容扩展受限，起名前要和用户确认赛道宽度。
- 搜索友好：不用谐音（用户搜不到），不用 momo 这类烂大街的名字（搜索结果太多，找不到你）。

**简介**（直接写出可复制的成品，四段式）：

1. 我是谁＋实力背书（一句话，用数字、头衔强化；只用用户给过的事实）。
2. 提供什么价值（关注你的理由）。
3. 主要内容方向（预告会持续分享什么）。
4. 价值主张／态度（核心理念）。

参考结构：「我是 XX，X 年 XX 经验｜XX 成果｜分享 XX｜XX｜XX｜一句话态度」。

**头像**：清晰、有辨识度、高度匹配人设。强 IP 定位建议真人照（增强信任）；不露脸就用高质量作品图或主题相关的设计；风格与整体视觉统一。

**封面与主页**：封面的色调、构图、字体、版式相对统一，形成视觉秩序感；一个画面的主色不超过 3 种。风格匹配人设：知识博主简洁明了，生活美学博主重氛围感。前期可以测试不同风格，跑出数据好的就固定下来；按选题分类建合集，方便新访客快速了解你。背景图简洁美观即可，不强制。

**语言**：给 3 条「说话规矩」，具体到下一篇就能照做，例如「开头第一句先给结论或场景，不说大家好我是 XX」「多用数字和真实经历，少用形容词」「结尾停在一个判断或一个能做的动作上」。

## 7．一句话定位公式

> 我是「人设」，通过「内容形式」，帮助「目标人群」，解决「具体问题」，并通过「变现方式」赚到钱。

暂不变现的用户，最后一段换成想得到的结果，比如「攒出一套能拿去面试的作品集」。

示例：我是一位新手妈妈，用真实的图文与场景视频，陪伴 0—1 岁宝宝的妈妈一起成长，提供科学的育儿知识与辅食技巧，赚到母婴品牌的广告费。

## 8．选方向：坡长不长，雪厚不厚；两个方向打架时怎么选

**先看两件事**：

- **坡长**＝需求能不能持续：十年后这件事还有没有人需要？是长期刚需，还是一阵风？
- **雪厚**＝有没有不只拼价格的空间：客户会不会只看便宜？有没有机会靠专业、信任、审美卖出溢价？

坡长但雪薄（大家做得都差不多，只能拼价格）的方向，做起来很累。向外看需求和溢价，向内看三件事：**能力**（哪些经历让他做这件事不违和）、**资源**、**阶段**（二十岁做是试错，四十岁做是重仓）。真正的起点＝市场机会和他自身条件的交叉点。

**组合本人资产，而不是先选产品**：一位 35 岁、在职做项目经理、刚开始学 AI、有孩子、想做副业的学员，单看哪个身份都撑不起一个方向，组合起来就是「AI＋职场副业成长」。先把他已有的身份、经历、能力和阶段列出来，再找交叉点。

**品类和特性**：品类是客户做决定时脑子里的那一格（想买空调，不会说「想买点制冷」）；特性是这一格里只有你有的购买理由（「抗敏感的牙膏」）。没进对品类，客户有需求时想不到你；没有特性，就只能拼价格。

最后定三件事：什么值得做、先做什么、**什么不做**。「什么不做」最难，也最重要。

**两个方向打架时**，逐个过这张表，选一个先做，在方案里说清另一个为什么暂缓：

| 看什么 | 问题 |
|---|---|
| 擅长 | 他在这个方向有没有拿得出手的经验和证据？ |
| 喜欢 | 写到第 50 篇还愿不愿意写？ |
| 离钱近 | 到第一笔钱要几步，卡在哪个门槛？ |
| 门槛 | 换个人照抄，还有没有他的经历和视角？ |
| 执行 | 按他每周的时间和技能，能不能稳定产出？ |

几个能力能合成一个方向时，优先合成（「会计＋电商运营」合成「懂钱的运营」）；硬凑的跨界（「健身摄影 AI 跨界导师」）不要。

## 9．对标账号（定位的验证与参照工具）

**为什么要找对标**：取长补短、避开与大号正面竞争、学习同行的起号路径和变现模式。

**新手期找什么样的**（方案里给用户的找对标标准）：

- 容易模仿：封面制作难度低、内容结构简单。
- 5 万粉以内；或同样刚起号但涨粉快的号；或低粉爆文。
- 非蓝 V 且持续更新 → 说明是靠自然流做起来的，值得模仿。
- 运营 1 年以上但近期爆文少、涨粉平的号，不值得对标。

**分析要点**（速查规则）：

- 粉赞比 1:10 上下算健康。
- 别只看点赞：点赞一两百，但评论三百多且都是「求购买」「求推荐」→ 值得模仿。
- 评论区吸引的是同行而不是精准客户 → 不值得对标。
- 人设、身份、视角自己模仿不了的 → 不参考它的人设。
- 变现效率差的 → 不值得模仿。

**怎么找**：搜赛道核心关键词（别搜太小众的长尾词）／关注后看相似博主推荐／垂直频道页／信息流多刷同赛道内容／用第三方数据工具筛近期涨粉快的号。

**元素级对标（重要原则）**：不要对着一个账号 1:1 抄。细分行业经常找不到完全对口的账号，把运营拆成元素，每个元素单独找最好的样本：

- 定位对标：学「帮谁解决什么」，内容方式可以完全不同。
- 选题对标：问这个选题戳中了什么需求。
- 标题对标：反常识、情境有感而发、亮身份、高情绪；可以把对标的标题批量丢给 AI 总结风格再仿写。
- 开头对标：前三句为什么能留住人。
- 内容对标：信息密度够大，每一段都有新信息。
- 封面对标：0.5 秒内抓住注意力，别花里胡哨分散注意力。
- 视觉风格对标：拍剪能力有限，就别模仿电影感大号。

对标的最终目的是**启发思考、优化自身、形成差异**，不是抄袭。
