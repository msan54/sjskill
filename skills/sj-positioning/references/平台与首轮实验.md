# 平台、成长阶段与冷启动

本文件供方案的「内容类型」「成长路径规划」「落地执行建议」三部分调用。

## 1．平台怎么选

用户指定了平台就按他的来，不凭刻板印象让他换。没想好的，默认推荐小红书：普通人起号成本最低，图文就能验证选题，搜索流量能吃很久。

| 平台 | 先做什么最容易跑通 | 用户要准备什么 | 容易踩的坑 |
|---|---|---|---|
| 小红书 | 能被搜到的具体问题、图文步骤、真实体验、选择对比 | 一组作品或过程图、一个把问题说清楚的标题 | 收藏多不等于有人来问；只堆关键词没用 |
| 公众号 | 值得讲透的判断、经历和完整方法 | 能持续写的文字、一个能把文章转出去的熟人圈子 | 写成短视频那样只有开头，解释和证据就不够 |
| 抖音 | 画面里马上能看见的冲突、过程和结果 | 能说能拍、固定的拍摄场景、能写口播脚本 | 文稿写得好不等于视频成立，要看画面和停留 |
| 视频号 | 熟人或同行愿意转给别人看的解释和示范 | 可信的表达、已有的熟人和同行关系 | 别把朋友圈的点赞当成公开流量的效果 |

- 不出镜也能做：屏幕演示、手部过程、实物和场景、图文讲解。
- 不要把小红书那套标题和封面写法，原样搬到公众号长文和短视频上。
- 先主做一个平台，跑通了再把内容改写到第二个平台；起步就多平台同发，最先耗光的是用户的时间。

## 2．成长三阶段（方案的「成长路径规划」按此写）

1. **快速起号期（0—1 万粉，验证期，约 1—3 个月）**：多模仿爆款笔记，赛道定好就行，有没有人设关系不大，先把数据和粉丝做起来。
2. **强化人设期（1—10 万粉，增长期）**：有粉丝基础后加入人物出镜、实拍、个人故事，人设加持下涨粉更快、变现效率更高。
3. **扩散定位期（10 万粉以上，成熟期）**：细分赛道必遇瓶颈，这时拓展内容边界（教穿搭的切入服装测评、美妆护肤），强化 IP 影响力。

一句话：**先用数据起号，再用人设放大，最后用 IP 破圈。**

写给用户时：

- 结合他每周的时间给**现实的节奏预期**。每周 3 小时和每天 2 小时，同一个阶段走完的时间差好几倍。
- 粉丝档位和月份是经验节奏，不是承诺，禁止写成「一个月涨到 1 万」。
- 已经有基础的号，从他现在所处的阶段写起，不让他重走新手起号。

## 3．冷启动方法（方案的「落地执行建议」按此写）

**核心理念：小步快跑、测试迭代，不是盲目堆量。** 启动期的目标是验证定位有没有被市场认可，找到能持续的内容模式。起号期先靠数量跑过概率：前 20 篇的任务是试出能跑的选题和形式，不是篇篇爆。

**控制变量 AB 测试**：

- 每次只改一个变量：笔记 A 发布 → 复制改封面或标题发 B → B 好就在 B 的基础上改开头或结构发 C → 以此类推。
- 看发布后 3—6 小时的短时数据判断趋势；数据极差（比如 3 小时 200 曝光、1 个赞）及时隐藏或删除，然后复盘。
- 一天可以发 10 条左右快速测试；但有效试错＞海量发布，初期每天 1—2 组有意义的测试就够。
- 测试是为了积累认知，初期数据差不要气馁。

**图文还是视频**：新手强烈建议图文冷启动——制作快、修改易、成本低，适合快速验证选题和文案。视频门槛高、问题排查复杂（分不清是脚本、拍摄还是剪辑的锅）。图文跑通能火的内容模式后，再把它拍成视频。

**创作目的要明确**：现阶段发内容是为了什么？验证定位、涨粉、引流还是给接广告铺垫？目的不同，内容侧重就不同。内容制作成本排序：原创视频＞原创图文＞贴图二创，初期选高效的形式快速测试。

**按时间排节奏**：先算一篇要多久（找素材、写稿、做图或拍剪、发布后看数据），再定每周发几篇。用户说每周 3 小时，一篇图文大约 1.5—2 小时，那就是每周 1—2 篇，别排成日更。
