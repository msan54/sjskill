# 来源与覆盖：怎么读、怎么保证不漏

适用于 A1、A2、A3。碎碎念短，整篇读完就行，不用这一套。

## 一、一份还是一批

先分清是一份录音，还是同一场活动的多个文件。

- 同一天、同一地点、同一场活动连着录的几个文件，按时间和上下文排好，当一批处理。
- 一批里有开场、讲课、答疑、闲聊、项目展示的，先给每段标上是哪种，再分别提取。
- 不同的活动，主题再像也不并成一批。
- 每个文件记下：路径、字数、指纹、时间范围、在这一批里排第几。

录音软件常常同时给一份 AI 摘要和一份完整转写：

- 摘要只用来找主题、定位在哪一段，不当事实来源。
- 完整转写才是证据；摘要和转写对不上，以转写为准，并标出冲突。
- 同一件事在摘要和转写里各出现一次，只提一次。
- 只有摘要、没有完整转写的，标「来源不完整」，不能说整份都整理过了。

原稿只读：不改写、不悄悄纠错、不补缺的内容。

## 二、按长度决定怎么读

按字数判断，不按文件大小。能跑命令就用 `wc -m 文件路径` 数字数。

| 多长 | 怎么读 |
|---|---|
| 一个文件，3 万字以内 | 整篇读两遍：第一遍画主题地图，第二遍逐条提取 |
| 一个文件，超过 3 万字 | 按时间戳、话题转折或章节分段读 |
| 同一场有 2 个以上文件 | 按顺序一个个读，读完再跨文件合并 |
| 结构乱、没有时间戳 | 先按换人说话和话题转折划段，再读 |

主题地图＝这一场按先后讲了哪几件事，各在第几分钟或第几段。

长稿分段的规矩：

- 尽量在自然的地方切，不把一句话、一个问答、一个案例切成两半。
- 每段 8000—12000 字。
- 相邻两段留 300—500 字重叠；重叠里的内容只记一次，第二次出现标「边界重复」。
- 没读完所有分段之前，不写最终摘要、不判断整场主线、不动知识库。

## 三、分段提取账本

每读完一段，先在当前对话里记一本临时账，不另建文件。每条至少记：

| 字段 | 记什么 |
|---|---|
| 来源位置 | 文件名＋时间戳；没有时间戳写章节或行号 |
| 谁说的 | 能确认的名字或角色；确认不了写「说话人 A（待核对）」 |
| 主题 | 这一段在解决什么问题 |
| 类型 | 概念／观点／方法／案例／数据／原话／决定／待办／冲突 |
| 内容 | 保留原意，不提前压成一句空话 |
| 证据和边界 | 数据、案例、什么情况下成立、例外或反例 |
| 打算放哪 | 整理稿／素材库／客户原话／方法论／课程主知识文档／选题／只留原稿／跳过 |
| 状态 | 新的／段内重复／边界重复／待核对 |

账本只为这一次服务。全部分段读完，再合成主题地图和正式整理稿。

## 四、谁在说话，转写里的错字

先建说话人对照，再分观点归谁：

- 靠自我介绍、互相称呼、角色信息和前后文确认是谁。
- 同一个人的不同叫法统一成一个名字，原来的叫法也留着。
- 确认不了就保留「说话人 A」，不为了整齐猜名字。
- 观点、案例和决定都写清是谁提的；几个人一起讨论出来的，写「共同讨论形成」。

转写里的错字和杂音：

- 口头禅、无意义的重复、语气词可以省。
- 专有名词、数字、时间、人名拿不准，保留原文，标「待核对」。
- 明显的同音错字，在不改变事实的前提下可以改，关键处保留原词说明。
- 断句错了，先结合上下文还原；有两种读法都留着，不替说话人选。

## 五、全部读完后：合并和防漏

按顺序做：

1. 合并同一主题跨段的记录。
2. 删掉边界重复，留来源最清楚的那一条。
3. 同一个观点讲了好几次，记「反复强调」，正文不重复写。
4. 同一个案例后面补了结果，合成一条完整的前因后果。
5. 前后说法不一致，保留冲突，不拿后面的悄悄盖掉前面的；后面明说「刚才那个数字说错了」，记更正后的数，并注明在哪更正的。
6. 出一张整场主题地图，再开始写正式整理稿。

## 六、覆盖检查

整理稿写完，从原稿结尾往前，对着主题地图和账本查：

- 每个方法有没有写清：要什么输入、分几步、产出什么、怎么判断、什么时候不适用？
- 每个案例有没有：背景、做了什么、结果、数字、前因后果？
- 每个重要结论有没有：谁提的、依据是什么、在原稿哪里？
- 每个问答、异议、决定和待办有没有写清归谁？
- 有没有强结论混进了原稿里没有的推断？
- 每个跳过的片段有没有写理由？
- 一批多个文件的，是不是每个文件、每个时间段都覆盖到了？

每个有价值的片段都要有去处：进了整理稿、待比对、待核对、只留原稿，或者写明为什么跳过，不能悄悄漏掉。

覆盖结果至少报这几个数：原稿文件数、主题数、方法数、案例数、原话数、待核对数、明确跳过数、没覆盖的片段数。没覆盖的片段数不是 0，不能说做完了：先补读，或者说明哪段读不到、为什么。

覆盖检查只能证明看得到的转写都读过了，证明不了转写本身没漏音、没错字。
