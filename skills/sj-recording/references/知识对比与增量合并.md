# 知识对比与增量合并

适用于要把录音里的东西写进素材库、客户原话、方法论、课程主知识文档或选题库的时候。A2、A3 必读；A1、B 有东西要写进知识库时读。

## 一、比之前先准备

先写完整理稿、列好要写进去的候选，再去查旧的。不边提取边写入。

每个候选至少记：

- 标题和类型
- 核心结论或事件
- 人物、对象和适用场景
- 数据、案例和在原稿哪里
- 3—8 个检索词：主题词、同义词、人名、案例名或方法名
- 打算写进哪个文件

## 二、去哪查、怎么查

按顺序查：

1. `输入/录音/已处理/` 里同一个人、同一主题的旧整理稿
2. `素材库/真实案例.md`
3. `素材库/客户原话.md`
4. `方法论/` 里相关文件的文件名、标题和正文
5. `输入/课程学习/` 里同一位老师、同一套知识的资料
6. `选题库/` 里同一个角度的选题

查的要求：

- 先用原词搜，再用同义词、旧叫法和场景词扩大范围。
- 只搜到文件名不算查过，要打开最相关的文件，核对意思、来源、适用场景和版本。
- 每个判断都写出旧内容在哪；没找到的，写清查过哪些地方。
- 不能因为措辞像就判重复，也不能因为措辞不同就判全新。

## 三、六类差异

| 类型 | 怎么判断 | 怎么处理 |
|---|---|---|
| 完全重复 | 核心结论、事件、前因后果和适用场景都一样 | 不写，只在整理稿里记下已有位置 |
| 换了说法的重复 | 换了表达或听众，说的还是同一件事 | 补上这次的来源；没有新信息就不改正文 |
| 新场景、新证据 | 核心不变，多了对象、反馈、数据、结果或案例 | 追加到原来那一条的证据或适用场景里 |
| 升级或修正 | 改了步骤、边界、判断标准或旧结论 | 更新成现在有效的版本，旧说法记进版本变化 |
| 冲突待确认 | 新旧说法不能同时成立，证据又不够裁决 | 两说都留，标出各自的来源和待验证的问题 |
| 全新内容 | 知识库里没有同义的知识或同一个案例 | 新建，补齐来源和应用 |

先后顺序：完全重复和换了说法的，先不新增；近似的，先补场景和证据；只有说的确实是另一件事，才新建。

## 四、案例和客户原话怎么去重

案例看「事件＋人物＋前因后果」，不看文字：

- 同一个案例讲给不同的人听，还是一条案例。
- 新听众的反应、追问和异议，补成这条案例的「听众反馈」。
- 同一件事后来有了新结果、新数据或新教训，更新原来那条的结果。
- 不同的事证明同一个观点，算这个观点的新证据，不复制一份观点。
- 细节看着像，但人物、动作或结果不同，不能合并。

客户原话：

- 必须留真实原句、是什么样的客户、日期和来源。
- 同一个客户反复说同一个意思，不重复记。
- 不同客户说了相似的话，记成新的原话证据，顺便记下出现了几次。
- AI 改写的、用户转述的、客户本人说的原句分开放，不把转述当原话。

## 五、同一位老师上了好几次课

按「老师＋他那套知识」归并：同一位老师讲两套不同的东西，分开放；课名不同、底下是同一套，合并。

分三层放：

1. 原稿：留证据，不改。
2. 单场整理稿：这次讲了什么、比以前多了什么。
3. 主知识文档：只放现在最完整、最有效的那一版。

新的一节课进来时：

1. 找到已有的主知识文档。
2. 按章节逐项对：定义、步骤、判断标准、边界、案例、应用。
3. 标出重复、补充、新模块、升级或修正、冲突。
4. 只补了案例、解释和边界的，升小版本，比如 v1.1。
5. 核心框架、步骤或判断方法变了的，升大版本，比如 v2.0。
6. 在「版本变化记录」里写：日期、哪节课、哪类变化、原来怎么说、现在怎么说、影响哪几节。

每个知识点挂两个链接：

- `📌 来源`：课程名＋日期＋章节或时间戳，可以列好几个。
- `🎯 应用`：用户自己真实会用到的地方；没有就写「待补」，不编。

后说的不一定对：只有老师明确说了「以前那个说法不对」，或者证据足够，才把旧说法标成已替换；否则两说都留。

## 六、写入前先列计划

| 候选 | 差异类型 | 旧内容在哪 | 打算怎么处理 | 写进哪个文件 |
|---|---|---|---|---|

这张表就是开工前确认的「要改动」那一行。用户确认后，计划里的新增和增量更新一次做完，不再一条一问。遇到下面这些停下来问：

- 要用新结论替换旧结论，但替换关系说不清；
- 新旧知识冲突大，需要用户拿主意；
- 找不到合适的文件，准备新建一个方法论主题；
- 实际要改的超出了确认过的计划。

不删旧知识。需要淘汰的，在主知识文档里标成历史版本。

## 七、各类东西写到哪

- 用户自己的新认知、故事、现场感受 → `素材库/真实案例.md`
- 客户、学员本人说的原话 → `素材库/客户原话.md`
- 能重复用的框架、流程、判断标准 → `方法论/`
- 同一位老师的知识 → `输入/课程学习/` 里对应的主知识文档
- 新的内容角度 → `选题库/`；同一个角度只补新证据，不重复建选题
- 课程结构、作业和案例给的启发 → 先写在整理稿里，用户确认后再改正式文档
