# 选题卡与写作交接

## 一、从定位接哪些信息

只读取用户指定报告或本次提供的信息。报告不是选题可用性的证明，也不是每张卡都要抄一遍的简介。

| 定位字段 | 对选题有什么用 | 没提供时 |
|---|---|---|
| 目标读者及具体处境 | 写清这条题想回答谁的问题 | 从已有原话识别；无法确定就待确认 |
| 解决的问题、内容支柱 | 给母题和候选分组，圈选时看覆盖 | 按当前主题展开，不强制先建立支柱 |
| 平台与呈现形式 | 决定图文、长文、口播或展示是否能交付 | 暂记待定，写作前补齐 |
| 搜索关键词 | 搜索导向内容使用读者实际提问方式 | 标候选词；没有验证不称高频词 |
| 可用素材与差异依据 | 配真实故事、数据、过程或观点依据 | 明确缺什么，不能推造用户经历 |
| 禁谈红线 | 排除用户明确不愿涉及或公开的内容 | 沿用当前请求，不擅自发明其价值立场 |
| 内容目标、首轮实验 | 推荐时区分解释、共鸣、信任、传播或商业目的 | 目标待确认，不自动加卖货任务 |

用户本轮说明与旧报告冲突时，以本轮明确要求为准，卡片注明采用哪份信息。文件没有版本号，就记报告日期或来源，不自行编版本。

## 二、卡片格式

一题一文件，文件名为标题；清理文件系统不允许的字符即可，不随意改题意。同题已存在时先展示差异，获得更新授权再追加；不同角度可以用明确后缀区分。不得自动批量覆盖或移动旧卡。

以下是格式示例，实际生成时填写真实信息或“待确认”，不要留下无说明的尖括号占位符。

```markdown
---
类型: 选题
选题: 离开字帖就不会写，下一轮练习该检查什么
创建日期: YYYY-MM-DD
状态: 待写
素材状态: 部分
平台: 待定
呈现形式: 图文或短视频，写作前确认
---

# 离开字帖就不会写，下一轮练习该检查什么

目标读者：想把练字用在日常记录里的人。
读者处境：临摹时能跟上，独立写时又回到原来的样子。
核心问题：怎样知道自己练到的是跟随动作，还是独立书写？
角度判断：先做一次离帖检查，再决定下一轮练什么；此为待验证教学假设。
内容目标：让读者识别自己的练习断点。
母题／骨架：练习如何迁移到日常使用。
需求证据：虚构教学示例，不能当作真实评论或用户经历。
素材及来源：目前只有问题描述；缺可核查练法、示范和适用边界。
素材状态：部分。
后续动作：找一种有依据的检查方法及其限制，才能写操作建议。
定位依据：未提供定位报告，来自本次主题。
时效：无已知截止。
```

上例仅解释格式，不能作为用户成果直接入库。

选题卡的必需信息是：选题、目标读者、读者处境、核心问题、角度判断、平台、呈现形式、内容目标、素材状态、素材及来源、后续动作。相关字段未知可明确待确认；缺失不阻止用户选中，但要留下具体补充任务。

素材状态：

- **齐全**：按当前角度写作所需的主要事实、来源和边界已有依据，仍需写作时核对。不是证明必定好看或必定有效。
- **部分**：有问题或部分事实，缺关键步骤、细节、对照或来源。写明具体缺口。
- **缺失**：只有方向，尚无可支撑核心承诺的材料。它可以存为待研究选题，不能直接写成亲历故事。

不强制使用 S／A／B 或预测流量等级。需要排优先顺序时，写实际理由：已有材料、用户当前重点、明确时效、待补成本。

## 三、保存与状态

只有用户圈选并要求保存时才落盘。给候选或给推荐本身不等于授权保存。保存到指定知识库的 `选题库/` 或用户指定目录；没有目录信息先交文本卡，不在当前目录随意建库。

状态保持简单：待写、写作中、已写、已发布。状态变更有对应事实或用户确认才更新。用户说“先停一下”可以记暂缓；保存一个选题不能自动称其为已写。发布状态和成稿链接仅在真实发布或用户确认后填写，不自动移动卡片。

若用户要求总览，可根据现有卡片生成，注明统计时点；状态仍以各卡为准，避免维护两份相互冲突的状态。未圈选的候选不批量造卡。

## 四、交给写作者

写作前提供：本次选中的题、要回答的问题、判断与证据、可用素材及归属、尚缺材料、形式、目标、用户红线。搜索内容额外带关键词与搜索意图；亲历内容额外核对事件和对话；解释型内容额外核对资料出处和适用条件。

写作者发现材料撑不起标题时，先缩小承诺或补材料，不靠编造消除缺口。卡片仍有价值；更改结构性角度时说明变更，并保留原来的需求证据。
