# 叁斤风格：取值与设计理由

这套取值沿用叁斤指定的公众号样式。[渲染脚本](../scripts/render.py) 里的 `make_style()` 是它的实现，修改参数时同步本说明。

## 一句话

**层级不靠字号，靠颜色和字重。** 正文灰、分节标题橙、重点句蓝，全文统一 15px。

## 取值

| 角色 | 取值 |
|---|---|
| 正文 | 15px ／ 行高 1.75 ／ 字间距 0.1em ／ `rgb(63,63,63)` ／ 段距 24px |
| 字体 | Optima、苹方细体优先，回退到衬线体 |
| 分节标题 | 橙 `rgb(255,104,39)` ＋ 加粗，字号与正文相同 |
| 划重点 | 蓝 `rgb(0,82,255)` ＋ 加粗 |
| 纯加粗 | 加粗，颜色仍是正文灰 |
| 引用块 | 左侧 3px 橙色竖线 ＋ `#f7f7f7` 浅灰底 ＋ 文字 `rgb(90,90,90)`，字号行高与正文一致 |
| 列表 | 橙色圆点，悬挂缩进，项间距 8px |
| 分割线 | 1px `rgb(229,229,229)`，上下 32px |
| 页面 | 最大宽 750px，内边距 22px，白底 |

## 为什么这样设计

1. **15px 而不是 16px 以上**：手机上一屏能多放两三行，字间距 0.1em 补回呼吸感，读长文不累。
2. **标题和正文同字号**：公众号长文的分节标题主要起「换气」作用，不需要大字号吓人。用颜色区分足够，页面更整齐。
3. **分节标题输出成段落加粗，不用 `<h2>`**：尽量减少目标编辑器默认标题样式的影响，仍需以粘贴后的预览为准。
4. **字间距写到每个元素上**：复制时减少对外部样式表的依赖，实际效果以使用中的编辑器为准。
5. **蓝色只划重点**：一篇 3–10 处。蓝色一多，读者就分不清哪句真正重要。
6. **引用块一篇最多 3 处**：引用块是「停一下」的信号，多了就失去作用。
