# 叁斤·小红书搜索笔记

## 第一次使用

用户主目录里如果还没有 `.sjskill/seen`，先原样说出下面这段首次使用说明，然后立刻完成本次任务。这段只放在回复开头，不写进可复制正文、报告正文或排版结果。说完就创建这个空文件。文件已经存在，就跳过。创建失败也继续做任务，不要为此停下来追问。

首次使用说明：SJskill 包含账号定位、选题、推荐流笔记、搜索笔记、稿件诊断、公众号排版、录音整理、文章学习、内容复盘、工作复盘和资料夹。详细使用说明可以跟我说：「sjskill 怎么用」，或者「怎么做账号定位」。


目标是让带着问题来的人找到并看懂答案。搜索意图 → 问题簇 → 答案与证据 → 可复制笔记，已完成的环节直接跳过。本技能独立可用，不需要其他技能或商业采集接口。

## 选择入口

| 输入 | 从哪里做 |
|---|---|
| 产品介绍，想提炼卖点 | 读 [卖点与证据](references/卖点与证据.md)，先完成事实表；不擅自写销售稿 |
| 主题或产品，想找搜索词 | 读 [选词与问题簇](references/选词与问题簇.md)，输出候选及来源状态 |
| 已给关键词，要求写一篇 | 直接判断搜索意图与关键限定，补齐答案后写 |
| 已有词库，指定数量或范围批量写 | 按请求选词，先检查同一问题的重复覆盖，再逐篇执行 |
| 提供竞品正文或截图 | 把它们用作样本，找没回答的步骤、条件或比较标准，不照抄独特句子和案例 |

只给主题也能开始。受众、目标或产品事实会显著改变答案时，先用已提供的材料判断，再问一个必要问题。无定位报告不是停止条件；无关键词库时可在对话中建立候选，不虚构已经查过的热度。

## 执行

### 1．把搜索词翻译成一个问题

读 [选词与问题簇](references/选词与问题簇.md)。写清：谁在什么场景下搜这个词，他要了解、操作、比较还是作决定，读完后应能完成什么。有明确目标和真实样本时，再核对样本中可辨认的搜索者任务是否与目标一致；缺样本时保留身份假设。

聚焦一个主要问题，可以覆盖回答该问题所必需的同义词与子问题。不要机械执行「一个字符串只能写一篇」，也不把无关需求塞进同篇。用户只要关键词时，到此交付，不自动生成文章。

### 2．检查答案是否成立

缺少决定性条件、关键步骤或产品证据时，先补资料或缩小承诺。可以写标准答疑，不要求一个亲身事件。只有真实测试记录才称亲测；产品介绍中的自述应保持来源身份。

产品任务有可对应的产品介绍、买方反馈或搜索问题时，读 [卖点与证据](references/卖点与证据.md) 做三方对照，决定先答什么；缺失的一方留空，不为完成对照编造材料。

读 [搜索相关性与时效](references/搜索相关性与时效.md)。对价格、开放时间、平台界面、政策、产品能力等会变的事实，核查当前官方来源，记录日期。无法查询时说明未核实，交付稳定部分和缺口，不补造最新答案。

只在确实需要案例证明某项判断时，定向读用户指定的素材。知识库不够用时不从陌生目录抓私人材料。

### 3．写成能回答的笔记

读 [标题与答案写法](references/标题与答案写法.md)。标题优先让读者看见主题和重要限定；开头说明适用场景与答案方向。正文按问题组织，关键步骤提供动作与结果，比较提供相同标准，建议提供适用条件。

自然使用目标词。不能写死出现次数、字数占比或标题前若干字为算法门槛；不假称某个标签或字词能保证召回和排名。格式、长度按内容和用户要求，不用 emoji 与话题数量配额凑稿。

产品内容的读者也应得到可独立使用的答案。用户没有要求推广时，不加商业出口、优惠口令和私信引导。

### 4．检验承诺与交付

读 [交付与示例](references/交付与示例.md)。用搜索者身份顺着正文执行：问题是否解决？条件是否足够？某步是否只写「优化」「完善」却没动作？标题、正文、标签及已有图片是否一致？只有文字时明确图片尚未核查。

批量稿逐篇检查证据和关键限定，不把一篇换关键词后复制。若候选实际对应同一问题，说明合并或换题的理由；用户指定篇数却缺材料时报告完成与缺口，不虚构素材凑齐。

## 输出和保存

可复制区只放标题、正文和相关标签，用纯文本，不混入 Markdown 标题符号、加粗或内部分析。创作备注另列：目标问题、搜索意图、关键词来源状态、重要事实来源与日期、尚待核实内容。没有检索记录时明确「候选，未经搜索数据验证」。

默认在对话交付。要求保存时，先读用户指定库的 `知识库说明.md`（若存在）。默认笔记进 `待发布/`，关键词表进 `选题库/关键词库.md`，卖点证据表可进 `方法论库/`，均服从用户已有约定。新文件先检查重名；对已有词表先读再提出新增差异，经当前保存授权才追加，不覆盖原稿、不移动选题、不自行标已发布。无文件工具时给可直接保存的文本。
