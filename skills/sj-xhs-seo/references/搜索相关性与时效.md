# 搜索相关性与时效

本文件提供编辑判断，不描述平台未公开的算法、固定权重或流量池门槛。文章相关、清楚、有证据是值得控制的事情，排名受多种因素影响，不能从文案自检推得保证。

## 相关性查的是问题，不是次数

标题、开头、正文、图片和标签共同告诉读者这篇在回答什么。它们互相矛盾时，先修问题与答案的关系，不增加关键词密度。

例如标题说「没有打印机怎么标搬家箱」，正文却主要推荐打印设备，即使每段都出现「搬家箱」也没答好问题。反过来，用「手写编号」「物品清单」「拆箱顺序」解释方法，虽没反复重写目标词，也可以直接帮助搜索者。

一篇聚焦一个主要问题，但回答它常常需要子问题。决定是否拆稿，要看这些子问题是不是同一任务的必要部分，不看它们是否用了不同字符串。不要把正文篇幅比例说成平台评分阈值。

## 四项编辑检查

- **问题匹配**：搜索者希望做的动作，正文能帮助完成吗？
- **条件匹配**：预算、地域、设备、使用者阶段这些改变答案的条件，有没有一致？
- **答案质量**：有可执行内容、判断依据与必要限制吗？
- **时间有效**：答案依赖哪些会变化的事实，什么时候核对过？

这四项没有固定权重排序，也不要求账号永远只写某个品类。不要把「人群一致」变成限制创作者只能谈一种生活。

## 时效性落实到具体事实

| 信息类型 | 要检查什么 | 写法 |
|---|---|---|
| 价格、活动、营业时间、入口 | 当前官方页面、适用地区、截止条件 | 注明核查日期与范围，过期不称最新 |
| 软件步骤、产品规格 | 版本、系统、账户权限 | 写适用版本；界面变了就更新相应步骤 |
| 周期性安排 | 本次实际日期和安排 | 不直接把去年年份换成本年 |
| 通用操作和原理 | 前提是否仍成立，例子是否过时 | 无须编「最新」，变化处单独更新 |

不把健康、法律或金融内容标作永不过时。涉及这些专业事实时查权威来源，不能靠「仅供参考」弥补未经核实的实质建议，也不能假造专家审阅或资质。

没有联网工具时，完成稳定内容，列出必须核验的事实；不能声称自己查过。用户已给可靠、当前材料时可以据此工作，来源身份保留在备注。

## 本地内容

地点、交通、开放时段、预约和无障碍条件按任务需要给。只写能核实且适合公开的地址，不公开私人住址或实时私人位置。发布定位由用户按实际情况选择，不声称开启精准定位就能保证排名，也不伪装到访。

## 怎样验证改善

用户提供后台数据时，记录观察日期、发布时长、搜索来源、实际搜索词及相关互动。单次自搜位置不是稳定排名，缺搜索量数据不按零计算。

比较稿件时先对齐观察窗口和问题类型。标题修改后数据变化可以形成候选解释，不能排除发布时间、封面、曝光变化就直接宣布因果。实际运营结论要等真实数据，技能生成成功只证明产出了稿件。
