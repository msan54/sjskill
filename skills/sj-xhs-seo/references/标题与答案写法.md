# 标题与答案写法

## 标题先交代能解决什么

优先放主题与最影响答案的条件。「搬家纸箱怎么标」比「这招太有用了」更清楚；如果答案专门针对没有打印机的读者，把这个条件交代出来。以下例子均是虚构教学素材。

| 标题 | 判断 |
|---|---|
| 没有打印机，搬家纸箱怎么标 | 问题与限制清楚，正文必须能手工执行 |
| 搬家搬家搬家，纸箱标记攻略 | 同词堆叠没有增加理解 |
| 一招让你搬家零失误 | 结果承诺过大，材料无法保证 |
| 不知道写什么，先给箱子编号 | 可作角度标题；正文仍需交代标什么、怎么找 |

关键词应自然出现，但不能因此把句子变成检索字段堆叠。完整长尾词很绕时，标题抓住核心问题，正文用正常语言展开条件。字符限制以用户当前编辑器为准，不用固定前若干字断言平台算法。

## 不同意图采用不同答案结构

**操作型**：适用条件 → 准备什么 → 每步动作 → 看见什么算完成 → 容易卡住的情况。

**比较型**：比较对象与共同任务 → 相同评价标准 → 各自优缺点与代价 → 条件化选择。没测过就写资料比较，不能写亲测排名。

**原因型**：现象边界 → 可能原因与如何区分 → 对应处理。材料不足时并列解释候选，不把相关当因果。

**选择型**：先给影响决定的条件 → 用证据对照 → 谁适合谁不适合。产品广告也不能省掉主要限制。

结构是检查答案是否完整的工具，不要求正文显式写这些标题。用户只要一个短答案时不扩成教程。

## 把操作写到可以照做

「建立标签体系」没有动作。「给每个箱子一个不重复的编号，在手机备忘录记下编号和主要物品」有动作。接着要说明如何用：到新家时通过清单搜索物品，找到箱号再取箱。是否贴多个侧面、使用何种材料，要有任务根据，不额外编产品耐久效果。

必要步骤包含输入与结果。涉及工具时提供入口和操作前提，没看到当前界面就不硬写不存在的按钮。给出失败时的检查点，但不列无关的庞大排障树。

## 让读者知道为什么

建议紧挨着理由。例如先编号可以避免不同箱子都写「杂物」后无法区分。理由说明到足够执行即可，不为了显专业拼接陌生术语。

例子可以用假设情形，但明示它是演示。用户亲历优先保留真实细节，不能为了读起来更具体新增日期、金额和完整对白。

## 图文与标签

封面呈现正文真正回答的问题；步骤图要能帮助读者认出动作或结果。只有文字时，可以给需要的图片清单，不假称现图已合格。截图在教程中可能是有效证据，不把截图一律判为平台违规。

标签只选正文实际相关的主题、场景或对象，数量由需要和编辑器约束决定，不借无关热点。正文用纯文本，不为了所谓平台机制强制无空行；粘贴效果以当前编辑器预览为准。

结尾可以停在最后一步、一个判断或必要提醒。不要把正文答案藏起来，让读者先评论、关注或购买才获得标题承诺的内容。
