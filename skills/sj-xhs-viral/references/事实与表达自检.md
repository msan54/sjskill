# 事实与表达自检

## 第一人称逐句查

重点核对「我做过」「我当时觉得」「我现在会」「客户跟我说」以及具体时间、地点、金额、对话和结果。来源可以是用户本次输入、他指定的材料或可核查记录。没有来源就换成不声称亲历的解释、删除多余细节，或在备注中让用户确认。

把「查到」写成「试过」，把朋友经历写成作者经历，把资料顺序写成因果，都会改变事实。用户说「效果不错」不等于给了可用的比例；单张截图不证明完整购买、使用和成功过程。

假设可以帮助解释，但要明确「假设」「举个教学例子」。不能只在交付备注里承认虚构，正文却用纪实口吻让读者误认。

## 六个回看问题

1. **读者期待**：标题与开头让人等待的内容，正文回应了吗？感受被说准也算回应，不强制给教程。
2. **受众开口**：如果从一件小事谈到一群人的处境，中间相同的选择或代价说清了吗？精准教程可以保持窄。
3. **角度**：换了评价标准、解释或观察位置，还是只把标题写得更狠？无反差需要时不强求。
4. **情绪站位**：希望理解用户的地方有没有写成责备？批评是否有具体对象和根据？
5. **牵引**：事件、问题或操作是否接得上？关键疑问有没有失踪，结尾有没有突然换任务？
6. **表达**：读者在哪一句需要回头找主语、猜指代、拆抽象词？对那一句动手，不凭「像 AI」整篇推倒。

## 具体可以怎么改

以下为虚构教学例句。

| 原句 | 缺的是什么 | 局部改法 |
|---|---|---|
| 「要建立持续输出的能力。」 | 不知道现在要做什么 | 若材料支持，写清「先交一段能让同事判断方向的文字」 |
| 「这个工具释放了生产力。」 | 谁少做了哪一步 | 写成材料真实说明的操作变化；没有变化数据就不加倍数 |
| 「在这个日新月异的时代，学习尤为重要。」 | 与本篇的具体问题没有连接 | 从文章已经讨论的难题开始，不另加宏大背景 |
| 「真正的高手早就形成闭环了。」 | 比较对象和动作都含混 | 交代具体人在收到什么反馈后改了什么；不猜所谓高手 |

自然中文不等于必须短句，也不等于塞口头禅。必要术语、列表、冒号、排比和比喻可以保留；检查它们是否帮助理解。重复的翻转、每段相同的结语、连续抽象名词只有妨碍本文时才调整，不按次数扣分。

## 不把私下制作说明带上桌

正文不写技能名、内部文件路径、采集脚本、版本沿革、任务耗时等只有作者和助手关心的信息。数字若能帮助读者比较代价就保留；仅用于证明「我做了很多工作」就移入备注。

**正反例校准（虚构教学材料）**：

- 不合适的正文：「本稿已完成三轮事实审计，所有结论都能回到原始材料，以下只讨论有证据支持的部分。」这是制作过程说明，应移出可复制正文；正文直接进入要讨论的事。
- 合适的读者说明：「我只试过两次，目前还不知道人数更多时是否适用。」这会改变读者怎样理解结论，应保留在正文，不能因为带有保留意见就移进备注。前提是用户确实提供过这两次尝试。
- 合适的制作备注：「尚未确认原话中的金额，成稿暂未采用该数字。」不要把它改成正文里的「经核验，本文未使用不明金额」来展示谨慎。

需要读者知道的来源归属、虚构标记、适用条件和真实商业关系仍留在正文相应位置。正文与备注分开，是让两类信息各在有用的位置，不是隐藏影响判断的不确定性。

图文的文字和图片应相互支持。没有图片时只能完成文字自检。产品和专业事实需要相应证据，商业关系应按真实情况说明。平台规则会变化，有具体合规问题时查当前官方规则；这份自检不等于法律意见、平台审核或实际发布验证。
