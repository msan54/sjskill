# 完整示例

以下所有人物、经历和文字均为虚构教学材料。只演示如何处理输入，不可套成使用者的亲身经历。

## 示例一：材料足够，直接成稿

**模拟输入**：我准备开一个读书小组。先做了一张很完整的报名表，没人填。后来把邀请改成「周六一起读这两页，你愿意吗」，有两位朋友答应。我的判断是，第一次发起活动，先让人知道他来了会做什么，比把活动介绍得完整更重要。不要卖课，不加评论引导。

**写前决定**：面向想发起小活动却卡在邀请上的人。事件已经明确，不再做三个角度。只使用输入里的一张表、两页书和两位朋友，不补人数对比、具体地点、收入和朋友原话。

**可复制稿件示范**：

想邀请人来，先说清楚来了做什么

我准备开一个读书小组，先做了一张完整的报名表。表做出来了，没人填。

后来我换了个邀请：「周六一起读这两页，你愿意吗？」两位朋友答应了。

两次邀请讲的是同一件事，但后一种让人更容易知道要答应什么：周六，读两页书。不用先猜这是一个要长期坚持的组织，还是一次可以试试的小活动。

第一次发起活动，可以先把来的人要做的那件事说清楚。等有人愿意一起试，再补齐后面的安排。

我的报名表可以继续完善，但它没有替我完成邀请。

#读书小组 #活动组织

**备注**：事实来自模拟输入。「不用先猜」是对邀请表达的解释，不是假称两位朋友承认了这种心理。成稿没有声称方法普遍有效，也没有补造第一次报名表里有哪些字段。

## 示例二：只有话题，没有亲历

**模拟输入**：「写一篇关于做计划的笔记，你先想几个方向。」

**合适交付**：

- 计划太细时，改计划会不会占掉开工时间？适合有反复改表却没开始的材料。
- 一天排满以后，临时任务从哪里挤进来？适合有计划被打断、重新取舍的过程。
- 计划究竟写给自己执行，还是给别人检查？适合两种使用场景的比较。

这三条都是候选判断，尚未归给用户。此时不要直接写「上周深夜，我盯着空白文档……」。若用户接着说「选第二个直接写」，可写观点稿，用明确的假设情形说明临时任务如何挤占安排；不假造用户已经试出一个有效方法。

## 示例三：观点与事件并不相互支持

**模拟输入**：我连续几次用了某种日程表，还是完不成工作。想写「所有计划都是骗人的」。

**处理**：保留挫败和批评，但指出现有材料只支持「这张表没有解决工作量超出可用时间的问题」等有限判断；具体原因仍需看材料。可用强烈的个人感受作入口，正文不要把个体经历升级成所有计划无效。不能为了替强标题找理由编出第三方研究。

## 示例四：从解释不了的材料推到更贴切的解释

**模拟输入**：我想写这周为什么总开不了工。周一到周三，我每天都留了一个完整小时，待办一直写「把课程准备好」，可每次只改一会儿目录就退出。周四只有半小时，我把待办换成「给第一节补一个操作示例」，这次补完了。我的判断是，这次卡住和待办写得太大有关。写给总觉得要腾出大块时间才能开始的人。

**推导过程，放在制作备注中**：

1. 比较用的常见解释：「迟迟没开始，是没有完整时间可用。」这是本例的比较假设，没有调研，不声称所有读者都这样想。
2. 它解释不了的材料：前三天各留了一个完整小时，仍只改目录；周四只有半小时，却补完了示例。单说缺完整时间，解释不了这次动作的变化；但这也不能证明时间安排毫无影响。
3. 更贴切的解释：对这次经历，待办是否指向一个能完成的动作，也可能影响开工。「把课程准备好」没有交代这次先完成什么，「补一个操作示例」给出了停点。这个解释贴合用户已有判断，不外推成所有拖延的原因。
4. 成稿安排：先写这一次前后动作的差别，再给有限建议；不补心理独白，不把推导步骤的名字塞进正文。

**可复制稿件示范**：

半小时能做什么，先写进待办里

这周一到周三，我每天都留了一个完整小时，待办上一直写着「把课程准备好」。可每次打开文件，只改一会儿目录，又退出了。

周四只有半小时。我把这条待办换成「给第一节补一个操作示例」，这次补完了。

「把课程准备好」是我最后想得到的结果，却没有告诉我，这次打开文件先完成哪一件事。补一个示例就具体多了：补完这一处，可以先停下来。

至少这一次，我不必等到能做完整门课的时间才开始。手里只有半小时，就先写清这半小时要留下什么。

**备注**：事实和作者判断都来自模拟输入；未证明改写待办是唯一原因。若输入只是「怎样在待办里加一条事项」的精准教程，直接讲操作即可，不套这条解释推导。
