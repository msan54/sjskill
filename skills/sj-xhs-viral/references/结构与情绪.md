# 正文结构与写法

写正文时全程贴身的规范。字数 500—700 字（含标题）是经验参考值，这个长度完读率最好；但长度服从内容，材料撑得住就写长，撑不住就写短。宁可短而精，不要长而水。**用户自己改写过的段落，不拿字数去删他的真话**，只在你写的部分里控制长度。

## 1．文案基本要求（六条）

1. **简单易懂**：专业词口语化、具象化，降低理解门槛。
2. **像朋友聊天**：分享好物什么语气就什么语气，不要正式文风。
3. **排版舒适**：勤分段，每段两三行，emoji 分隔点缀。
4. **围绕选题**：所有内容服务于核心主题。跑题会导致流量分配跑偏——想做美妆却常发其他话题，吸来的就不是看美妆的人。
5. **真实体验**：具体细节和真实心得，拒绝空洞赞美。
6. **用户视角**：用户最关心什么、有什么疑虑？文案有没有回答？

## 2．四层结构（默认骨架）

1. **开头戳痛点**：第一句话必须让目标用户产生共鸣或好奇。四种开法：
   - 设置悬念：提出一个引人好奇的问题。
   - 直接点名困扰：直接说出他正卡着的那件事，不用「你是不是……」这类问句起手。
   - 共鸣场景：讲一个感同身受的场景。
   - 直接展示结果：开头就把成果告诉用户。

   用共鸣场景和展示结果开头时，「上周日」「晚上八点」这类时间点，必须是用户材料里真实有的。手里没有，就写常态叙述（「每周五下午都要交周报」），不许为了开头具体补一个——补出来的时间就是假具体。神态、天气、房间摆设、对白和心理活动同理。
2. **衔接造落差**：描述期待，让痛点与美好之间拉开落差。
3. **亮解决方案**：足够简单、拿来就能用。每个方法两三行，用序号或 emoji 分段；方法写几条由内容决定，不凑数。
4. **结尾留钩子**：停在一个判断、一个能做的动作，或者一个真问题上，说完就停。不用固定的结尾套话，不用「评论区扣 1」这类暗号；可以留一个信息钩子，让想继续了解的人有理由点开你的主页。

## 3．八大文案结构（按内容类型选用，替代四层结构的备选骨架）

| 结构 | 逻辑链 |
|---|---|
| 问题解决型 | 遇到问题 → 渴望改变 → 试了很多方法不行 →（转折）发现新方法 → 问题解决 |
| 经验分享型 | 展示成果或高光场景 → 过程心得与技巧 → 带来的具体改变 |
| 好物推荐型 | 引出产品或契机 → 多维度介绍（外观／功能／使用感／效果）→ 客观总结优缺点 → 适合谁 |
| 对比型 | 抛出对比主题 → 分别阐述 → 对比中凸显优势 |
| 信息整理型 | 点明主题（「XX 必备 N 个工具」）→ 清单式罗列 → 收藏价值 |
| 攻略教程型 | 明确目标 → 步骤化拆解 → 关键节点提示 |
| 避坑型 | 点出常见的坑 → 分析踩坑原因和影响 → 给正确方案 |
| 四段式介绍型 | 我是谁＋能给你什么 → 为什么今天分享这个 → 核心内容要点 → 引导关注 |

**四段式黄金结构**（情绪线版，适合带产品）：遇到问题（皮肤黑被嘲笑）→ 渴望改变（自卑想变白）→ 尝试无效（很多方法不满意还长痘）→ 发现解决（朋友推荐 XX 后明显变化）。每一段都要有用户真实的经历撑着。

结构服务事件：用户给的是一件完整的事，就顺着事情写，不为了套模板把真实叙事拆碎。一篇笔记只有一个最高任务——标题、开头、主体和结尾回答的必须是同一个问题。

## 4．实用写作技巧

- **代入法**：把读者想象成朋友。你会怎么跟朋友分享或炫耀这件事，就怎么写；写完删掉无关紧要的词句。
- **卖点提炼四维**（写产品时）：功能（有什么基础功能）→ 优势（比同类好在哪）→ 利益（这个优势给用户什么具体好处）→ 感知（五感体验和用户反馈）。
- **巧妙植入**：找「选题痛点」和「产品特点」的交集，从场景和痛点切入，产品作为解决方案出现，不突兀推销。
- **说人话**：不讲专业概念；用具体场景和真实经历来解释。比喻可以用，只排查喻体比本体还绕的比喻（「XX 的发动机」）。

## 5．情绪走向

允许焦虑、冲突和不甘，但不能全程低落、消极到底；结尾要给出一个新的理解、选择或状态，不强制给产品答案。

写完再回头标一遍：开头让人感到什么 → 中段 → 结尾。不要动笔前先填表——那样情绪会变成格式。标的时候拿下面五条路径对照，看这篇走的是哪一条、哪一步断了；写到中段发平、不知道往哪推的时候，也可以回来翻一翻。

### 五条情绪路径

每一条都是读者从点进来到愿意行动，情绪一步步变化的顺序。钩子句式是举例，换成用户自己的话再用。

**① 好奇 → 惊喜 → 满足 → 分享**
- 适合：新发现、冷知识、宝藏型选题、反常识的知识分享。
- 怎么走：开头制造悬念 → 拿出超出预期的东西 → 读者觉得值了 → 想转给别人。
- 钩子句式：开头「你绝对想不到 XX 居然能 XX」；中段「看到结果我自己都惊了」；结尾「这个谁还藏着不分享」。

**② 焦虑 → 希望 → 解决 → 安心**
- 适合：解决痛点、避坑攻略、帮读者找出问题出在哪。
- 怎么走：点出问题 → 告诉他有办法 → 拿出方案 → 打消他最后的顾虑。
- 钩子句式：开头直接点名困扰「一到 XX 就头大：XX」；中段「其实有个办法」；结尾「照着做一遍，下次 XX 就不用再 XX」。
- 注意：只用轻焦虑。点到读者认出自己就停，不写「再不学就被淘汰」这类吓人的后果——压力一过头，读者会划走，不会动手。

**③ 共鸣 → 认同 → 信任 → 行动**
- 适合：个人故事、价值观、个人 IP 的日常内容、想让读者来找你的笔记。
- 怎么走：先让他觉得「你懂我」→ 认同你的判断 → 信你这个人 → 愿意关注、点开主页、来找你。
- 钩子句式：开头「我也是 XX 的人，所以特别懂……」；中段「这种感觉只有我们这种人才懂」；结尾停在一个判断或一个能做的动作上，不加评论引导。
- 注意：做个人 IP，这是主力路径。读的时候情绪不激烈，是一篇篇攒下「这人跟我是一类人」的信任。

**④ 向往 → 代入 → 体验 → 行动**
- 适合：生活方式、氛围感、好物种草。
- 怎么走：展示理想状态 → 让他把自己放进那个场景 → 写看得见、听得见、摸得着的体验 → 告诉他怎么过上这种日子。
- 钩子句式：开头「我理想的一天是这样的……」；中段「早上起来你会看到……」；结尾「想拥有这种生活的人，可以试试 XX」。
- 注意：体验那一段的画面和感受，必须来自用户的真实经历，不为了氛围编细节。

**⑤ 愤怒 → 揭露 → 教育 → 让读者有底气**
- 适合：行业内幕、避坑警示、犀利吐槽、替读者说话。
- 怎么走：指出不合理 → 说出真相 → 教他怎么判断、怎么避开 → 让他下次心里有底。
- 钩子句式：开头「XX 行业不告诉你的真相是……」；中段「你被收的智商税远比你想的多」；结尾「看完这篇你不会再被坑」。
- 注意：愤怒能拉高点击，也容易引战。慎用，一个账号里这类笔记不超过五分之一；揭露的事要有用户自己踩过、能核对的证据。

### 写完对照三问

1. 标题有没有触发这条路径的起点情绪？
2. 中段有没有一个情绪转折，还是从头到尾平铺直叙？
3. 结尾有没有落到这条路径的终点：一个能做的动作，或者一个想转给别人的理由？

再逐段对一遍：情绪有没有断掉，或者往回退。

拿 [完整示例](完整示例.md) 示例一那篇会议纪要标一遍：「一场会要折腾一个多小时」→ 累、烦，是轻焦虑；「二十分钟左右能交」→ 希望；三个步骤 → 解决；「AI 把同事的名字认错了，我差点直接发到群里」→ 读者心里一紧，这是转折；「交之前只核两样东西：人名、数字」→ 安心。走的是第②条，四步都在。要是标出来是「烦 → 烦 → 烦」，就是全程低落，回去补转折或者改结尾。

## 6．融入人设（四个方法）

1. 讲「我是怎么做的」，融入个人经验或看法。
2. 适当表达情绪：开心就是开心，不开心就是不开心。
3. 展示生活性格，让读者隔着屏幕感受到你。
4. 少装，真诚。

人设靠行为立住，不靠自我介绍宣布：说「我很靠谱」没有用，写出你怎么核对、怎么处理失误，读者自己会得出结论。

## 7．视频笔记三项检查（只对视频笔记）

1. **情境六要素**：人物、目的、行动、关系、问题或变化，以及帮助理解的环境、道具或声音。只写了一个地点，不算完整的情境。
2. **可拍动作**：至少写出一个能改变信息、关系或结果的动作，并注明它证明什么（比如「把录音文件拖进对话框，三秒后屏幕上出现三栏纪要」证明整理有多快）。走来走去、挥手、拿杯子不算表现力。
3. **互动点的位置**：只放在观众已经拿到信息、认出自己、或者情绪释放之后；开头吸引来的人、正文解决的问题、结尾邀请互动的理由，要指向同一件事。

时间较长的视频，隔一段就给一个进度提示（「第二步」「最后一个坑」），观众才知道还剩多少。只有脚本、没有画面时，只检查脚本拍不拍得出来，不判断成片效果。图文笔记不因为没有镜头和分镜扣分。

## 8．话题标签（3—5 个）

第 1 个：内容主题话题 → 第 2 个：场景或人群话题 → 第 3 个：情绪或态度话题 → 第 4—5 个：和内容相关的热门话题。只选和正文真正相关的，不蹭无关热点。
