# 选题与角度

选题是战略，不是碰运气。好选题自带流量，后续创作事半功倍。本文件供「帮用户挖角度」和「验证用户选题」时调用。

## 1．爆款的底层逻辑

**爆款 ＝ 用户需求 × 优质数据**：选题切中近期很多人关心、好奇、有共鸣的点，且笔记数据（点击率、互动率、完读率）能跑赢同类。

**两大核心价值**（每个选题至少占一头，最好兼具）：

- **实用价值**：看完就能用，解决实际问题。形式：攻略、教程、方法汇总、避坑指南、测评、大合集。用户获得感强，容易收藏和传播。
- **情绪价值**：引发共鸣、好奇、羡慕、向往。切入点参考人性底层：七情（喜怒哀乐爱恶欲）、六欲（食欲、颜值吸引、求知欲、参与感、崇拜跟随、占有省钱）。情绪价值带来更高的评论和转发。

## 2．选题从哪来（四条路）

| 路径 | 怎么挖 |
|---|---|
| 挖用户需求 | 爆款笔记下的高赞评论、高频提问＝用户真实需求的直接体现；发现痛点 → 提供解决方案，就是一个选题 |
| 内求于己 | 从用户的经验、感悟、观点、技能反推：「这个东西对谁有用？解决了什么问题？」每天的感受都是一个潜在的解决方案 |
| 平台趋势 | 小红书搜索框：下拉词、猜你想搜、搜索发现、相关搜索、大家都在搜——全是现成的选题；官方话题活动有流量扶持 |
| 对标学习 | 收集同领域近 7 天到 1 个月的爆款笔记选题；跨平台迁移（抖音、B 站、知乎、公众号的爆款能不能适配小红书） |

评论区和对标是找选题的后厨。写出来的笔记里不出现「刷到一条笔记」「评论区有人说」，把需求转成读者自己的心里话。

## 3．万能选题思考框架（维度组合）

四个维度自由组合出选题：

- **时间**：季节、节日、大促、人生节点（毕业季、结婚季）。
- **地点／场景**：办公室、宿舍、通勤、约会、旅行、卧室、厨房。
- **人物／人群**：学生党、打工人、宝妈、小个子、油皮、新手小白。
- **需求／痛点**：省钱、变美、提效、学习方法、情绪调节。

组合示例：夏季（时间）×防晒（需求）；毕业季（时间）×拍照技巧（需求）；周五下午（时间）×写周报（需求）×行政（人群）。

## 4．高爆率四方向

1. **广域共鸣**：触动大量人群共同情感的话题（高考、租房、职场焦虑、催婚、人际关系）。
2. **垂类深度干货**：特定人群的系统性解决方案（XX 行业面试全攻略、XX 从入门到精通）。
3. **大合集／强盘点**：信息量大、易收藏（XX 个宝藏 App、XX 款平价好物）。
4. **避坑／揭秘**：满足规避风险、获取内幕的需求。

## 5．给用户挖角度的规则（用户只给方向时）

给出 3 个切入角度，每个包含：

- 角度描述（一句话）。
- 为什么有爆款相（对应上面的价值类型和高爆率方向）。
- 2 个标题方向。

三个角度要拉开差异：一个偏实用价值、一个偏情绪共鸣、一个结合用户的独特身份或经历。禁止给三个同质化的角度——只换了形容词的，算同一个角度。

## 6．选题验证（动笔前快速过）

- 把核心关键词在小红书搜一遍：近期的爆款都是什么类型、角度、风格？用户的想法还有没有新意？
- 对比爆款与非爆款的差异点：标题？封面？切入点？
- 题目里的每个名词，目标读者身上有吗？「装了企业微信、做了客户分级表」每个字都真，但一个人干活的读者一眼划走。素材越具体，越容易带进读者没有的前提。
- 验证的目的是**降低失败概率**，优化角度和表达，不是找借口不写。

## 7．商单／带产品选题速查（用户目的是推广时用）

| 类型 | 打法 | 示例逻辑 |
|---|---|---|
| 痛点解决式 | 点出痛点，产品作为解决方案自然引出 | 「熬夜党福音！XX 实测 7 天变化」 |
| 前后对比式 | 直观展示使用前后的变化，事实说话 | 「坚持用 XX 一个月，肉眼可见的改变」 |
| 超级场景式 | 把产品放进用户向往的生活场景，制造代入感 | 「周末 brunch 的松弛感，全靠 XX 营造氛围」 |
| 特定人群＋方案 | 精准锁定一类人群的特定需求 | 「学生党平价好物：XX 性价比之选」 |
| 清单合集式 | 产品作为好物清单的重点之一，降低广告感 | 「年度爱用 Top5，XX 无限回购」 |
| 热点时令式 | 结合季节、节日、平台热点 | 「入秋第一杯 XX」「圣诞心意礼物」 |

商单铁律：品牌目标人群和账号粉丝画像相差太大的合作，建议用户放弃——会污染账号标签。实测数据（「7 天变化」「一个月」）必须是用户真的测过的。

## 8．内容形式怎么选

- **图文**：制作快、修改易、阅读门槛低，适合攻略、测评、合集这类信息密度高的内容；新手优先用图文验证选题。
- **视频**：冲击力强、容易建立信任、点击率天然更高，但制作门槛高；图文跑通的选题可以视频化。
- **纯文字（大字报、备忘录截图）**：门槛最低，适合观点、金句、简短攻略、引发讨论。
